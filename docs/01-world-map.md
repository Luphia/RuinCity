# 01 · 世界與地圖

## 1. 世界規格

| 項目 | 數值 |
| --- | --- |
| 地圖尺寸 | 500 × 500 格 = 250,000 格 |
| 座標系 | `(x, y)`，原點 `(0,0)` 在左上，x 向右、y 向下 |
| 邊界 | 硬邊界（不環繞）。地圖邊緣為「深淵」，不可通行、不可佔領 |
| 地形 | 每格固定一種地形，賽季內不變 |
| 容納玩家 | **每場固定 600 人**（真人 + AI 補足），見 `13` §4、`15` |

### 為什麼是 500×500

600 人分佈在 250,000 格上只有 416 格／人——對 12 天的賽季太稀疏。
因此 **不把玩家灑滿地圖**，而是集中在三座遺跡周圍的環帶
（每陣營 200 人、約 33,300 格、167 格／人），
其餘 **約 60% 的地圖是荒野**。

荒野不是浪費，它承擔三件事：

- 廢土營地與廢棄倉庫的 PvE 舞台
- 攻城遠征的必經之路，讓前哨營補給線有意義（見 `02` §2.5）
- 邊陲玩家向外擴張的成長閥——不需要跟人搶的方向
- 最遠對角距離約 707 格；以最慢的攻城單位無法直達（見 `04-military-combat.md` 的行軍時間上限），
  **迫使遠征必須靠前哨營接力**，這是地圖尺寸刻意製造的戰略約束。

## 2. 地形類型

| 地形 | 代碼 | 佔比 | 行軍係數 | 產出修正 | 防禦修正 | 可否建據點 |
| --- | --- | --- | --- | --- | --- | --- |
| 平原 | `PLAIN` | 42% | ×1.00 | — | — | ✅ |
| 廢墟 | `RUBBLE` | 18% | ×1.10 | 資源 +15% | — | ✅ |
| 森林 | `FOREST` | 16% | ×1.30 | 木材 +25%、農田 −20% | 守方 +10% | ✅ |
| 荒地 | `WASTE` | 12% | ×1.15 | 全體 −20% | — | ✅ |
| 礦脈 | `LODE` | 6% | ×1.20 | 鐵／石 +40% | — | ✅ |
| 毒沼 | `MARSH` | 4% | ×1.80 | 全體 −40% | 守方 +15% | ✅ |
| 山脈 | `MOUNTAIN` | 2% | 不可通行 | — | — | ❌ |

- **行軍係數**取路徑取樣點的平均值（見 `04`）。
- **山脈**是唯一的不可通行地形，成群出現形成天然關隘，是聯盟劃分勢力範圍的天然邊界。
- 地形只影響數值，不影響格子能否被佔領（山脈除外）。

## 3. 地圖生成

賽季開始時以一組 **賽季種子（seed）** 決定性生成，任何人用同一 seed 都能重現同一張地圖。

### 3.1 演算法

```
1. 以 seed 產生兩層 Simplex Noise：
   - 高度層 elevation  → 決定 MOUNTAIN / LODE
   - 濕度層 moisture   → 決定 FOREST / MARSH / WASTE
2. 依門檻值分配地形，未落入任何門檻者為 PLAIN
3. 對 MOUNTAIN 做連通性檢查：
   - 移除面積 < 6 格的孤立山塊（避免地圖上散落無意義的障礙）
   - 確保地圖任意兩個非山脈格皆連通（floodfill 驗證，否則重新生成）
4. RUBBLE 以「古城遺址」為中心散佈：隨機 40–60 個中心點，
   每個中心以半徑 3–8 的衰減機率灑 RUBBLE
5. 放置三座遺跡（見 §4）
6. 產生出生點池（見 §5）
```

### 3.2 生成產物

地形層在賽季內**永不改變**，因此可在賽季開始時一次性預先產生為靜態檔：

- 切成 **64 × 64 的 chunk**，共 `⌈500/64⌉² = 64` 個 chunk
- 每個 chunk 序列化為緊湊二進位（每格 1 byte 地形碼 → 4 KB／chunk）
- 上傳至 CDN，路徑 `/terrain/{seasonId}/{cx}_{cy}.bin`，長期快取（immutable）
- 前端只在視野進入新 chunk 時下載

> 動態層（誰佔領了哪格、據點等級、聯盟顏色）走 API 查詢，見 `07-tech-architecture.md`。

## 4. 三座古老遺跡

三座遺跡在地圖生成階段隨機放置，但受下列約束以確保賽季公平：

| 約束 | 值 |
| --- | --- |
| 離地圖邊界 | ≥ 90 格 |
| 兩兩之間距離 | **≥ 170 格、≤ 240 格** |
| 三點構成的三角形 | 最小內角 ≥ 35°（避免三座擠成一直線讓單一勢力輕鬆全包） |
| 所在地形 | 強制改寫為 `PLAIN`，周圍 2 格清除 `MOUNTAIN` |
| 佔地 | 每座遺跡佔 **3 × 3 = 9 格**，中心格為遺跡本體 |

遺跡周圍 **半徑 12 格** 為「禁建圈」：不可建立據點、不可佔領為個人領土。
這片空地是會戰的舞台，也避免有人在賽季初直接把家蓋在遺跡上。

三座遺跡的名稱與差異化能力見 [`05-ruins-season.md`](05-ruins-season.md)。

## 5. 出生點與玩家分配

> **採用事先登記制 + 全員同時進入。** 完整規則見
> [`13-season-registration.md`](13-season-registration.md)，本節只摘要與地圖相關的部分。
>
> 原本的「外環螺旋入場」（依註冊順序由外向內填入）已廢除。
> 它是為了補償晚加入者而設計的補丁；同時開賽直接消滅了這個問題。

### 5.1 合法出生點

```
合法出生點 = 該格與其右下三格（構成 2×2 核心）皆滿足：
  - 地形 ≠ MOUNTAIN
  - 不在任何遺跡的禁建圈內（半徑 12）
  - 離地圖邊界 ≥ 10 格
```

### 5.2 三分天下：以遺跡為核心的區域分割

地圖依三座遺跡做 **Voronoi 分割**成三個陣營區域。
分割用的是**行軍成本距離**而非直線距離——山脈成本極高，
因此山脈自然成為區域邊界，三塊版圖的形狀從一開始就不對稱。

```
玩家在登記時選擇陣營（三選一，固定名額 200 人／陣營）
  → 決定生在哪一個區域
再選擇出生帶（前線 20–45 格 / 中原 45–78 格 / 邊陲 78–105 格，離該區遺跡）
  → 決定離遺跡多近
```

因為三座遺跡相距 170–240 格、而每個陣營版圖半徑約 105 格，
**兩個陣營的邊陲帶會直接接壤或極為接近**——
離自家遺跡最遠，就等於離敵對陣營最近。
沒有一個出生帶是安全的，只是危險的性質不同（見 `13` §2.2）。

分配以 **Poisson-disk sampling** 在環帶內產生候選點，
並通過五項公平性驗證（可建設格數、離遺跡距離、鄰居數、高價值地形、區域面積）
才會採用；任一項不通過就換 seed 重跑。驗證數值在封盤期公開。

### 5.3 出生密度（固定 600 人）

因為每場人數固定，環帶半徑也是固定常數，不需依人數縮放：

| 出生帶 | 半徑 | 每陣營人數 | 面積 | 每人格數 |
| --- | --- | --- | --- | --- |
| 前線 | 20–45 | 40 | ~5,100 | 128 |
| 中原 | 45–78 | 100 | ~12,700 | 127 |
| 邊陲 | 78–105 | 60 | ~15,500 | 259 |

環帶會被 Voronoi 邊界裁切；若某陣營的邊陲環被鄰區切掉太多，
外半徑自動向**遠離其他陣營的方向**延伸補足面積。

### 5.4 開局配置

| 項目 | 內容 |
| --- | --- |
| 核心據點 | 2×2，左上格為主堡 Lv1，其餘 3 格空地 |
| 起始資源 | 糧食 500 / 木材 500 / 石料 500 / 鐵 200 / 遺物 0 |
| 起始兵力 | 民兵 ×10 |
| 新手保護 | **前線 12h / 中原 18h / 邊陲 24h**，或主堡達 Lv6（先到為準） |
| 起始資源修正 | 邊陲帶 **+40%**；前線帶額外 **+1 領土容量** |

保護期縮短是為了配合 12 天賽季（原為 48/72/96 小時，
在 12 天裡等同於全季無敵）。24 小時仍保證至少一個完整睡眠週期的安全。

## 7. 地圖上的可互動物件

| 物件 | 說明 |
| --- | --- |
| 玩家核心據點 | 2×2，顯示玩家名、聯盟旗、主堡等級 |
| 玩家領土格 | 單格，塗上擁有者的聯盟色（無聯盟則為中性灰） |
| 外部設施 | 建在領土格上的農田／伐木場／哨塔／前哨營等 |
| 遺跡 | 3×3，顯示佔領進度環與當前控制聯盟 |
| 廢土營地（PvE） | 隨機刷新的中立敵營，Lv1–Lv10，清掉可得資源與少量遺物 |
| 廢棄倉庫（PvE） | 一次性寶箱點，先到先得，賽季內隨機刷新 |

**廢土營地**是新手期與非戰鬥玩家的主要成長管道，也讓地圖在玩家稀疏的區域仍有事可做。
營地每 90 分鐘在全圖隨機補充（`TIME_SCALE`），維持全圖約 800 個活躍營地。
它們大多分佈在**荒野**——那 60% 沒有玩家聚居的地圖，因此有事可做。
