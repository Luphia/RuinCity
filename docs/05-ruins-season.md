# 05 · 三座古老遺跡與賽季制

遺跡是 RuinCity 的**終局系統**。它們回答了一個所有長青 SLG 都逃避的問題：
「這場戰爭什麼時候結束？」

## 1. 三座遺跡

三座遺跡在賽季開始時隨機放置（約束見 `01-world-map.md` §4），各佔 3×3 格。
它們機制相同，但提供不同的**聯盟增益**，讓「先搶哪一座」成為戰略決策。

| # | 名稱 | 增益（給控制它的聯盟全體成員） | 遺物產出 |
| --- | --- | --- | --- |
| I | **灰燼尖塔** The Ashen Spire | 全體行軍速度 **+20%** | 48 / h |
| II | **沉沒穹窖** The Drowned Vault | 全體資源產出 **+25%**、地窖保護 **+50%** | 48 / h |
| III | **鐵之搖籃** The Iron Cradle | 全體單位攻擊與防禦 **+12%** | 48 / h |

遺物產出**平均分配**給控制聯盟的所有線上成員（過去 **12 小時**內登入過者）。
40 人的聯盟每人每小時得 1.2 遺物；10 人的小聯盟每人得 4.8。
→ 小而精的聯盟在遺物人均上有優勢，大聯盟在兵力上有優勢，兩者平衡。

### ★ 陣營級分潤

若**自家遺跡**由**同陣營的任一聯盟**控制：

| 對象 | 增益 | 遺物 |
| --- | --- | --- |
| 控制的那個聯盟 | **100%** | 全額 |
| 同陣營其他 4 個聯盟 | **50%** | 無 |
| 其他陣營 | 0% | 無 |

於是陣營內的 5 個聯盟既是敵人也是共犯：
你想自己拿下（100%），但拿不到時**寧願是同陣營的死對頭拿到（你還有 50%），
也不要落到外族手裡（0%）**。

夏季彼此廝殺爭遺跡，秋季一致對外守住它——
**這是 v1 唯一的「陣營意識」機制，完全由利益結構產生，不靠任何強制規則。**
見 [`06-alliance.md`](06-alliance.md) §0。

> 產出 48/h（原 12/h）套用 `TIME_SCALE = 4`；
> 線上判定收緊為 12 小時（原 48 小時），因為 12 天的賽季裡，
> 48 小時未登入已經等同於半退場。

### 為什麼是三座、增益為什麼這樣配

- **灰燼尖塔（速度）**：拿到它的聯盟更容易搶下另外兩座 → 它是「第一優先目標」，
  所以賽季中期的第一場大會戰幾乎必然在這裡發生。
- **沉沒穹窖（經濟）**：續戰能力。長期戰爭中最終決定勝負的。
- **鐵之搖籃（戰力）**：最直接，但也最容易讓局勢一面倒 → 因此加成刻意壓在 12%。

三種增益分別對應「機動 / 經濟 / 戰力」，沒有一座是可以放棄的。

### 遺跡 = 陣營 = 區域性格

因為採用事先登記制（見 [`13-season-registration.md`](13-season-registration.md)），
玩家在開賽前就選擇了要生在哪座遺跡旁。三座遺跡的增益不同，
於是**選陣營等於宣告玩法傾向**，同區域的玩家玩法相似，
三塊版圖會自然演化出截然不同的性格：

| 區域 | 自我選擇進來的人 | 預期演化 |
| --- | --- | --- |
| 灰燼尖塔區（速度） | 掠奪流、快攻流 | 春末就開始互相突襲，衝突頻繁但規模小、傷亡低。5 個聯盟名額最早被搶滿，也最不穩定 |
| 沉沒穹窖區（經濟） | 發育流、種田流 | 春夏最和平，5 個聯盟默契地互不侵犯。秋季最富，也最容易成為另外兩區的目標 |
| 鐵之搖籃區（戰力） | 戰鬥流 | 夏季解封就是血肉磨坊。存活下來的聯盟戰鬥經驗最豐富，但整體發育最慢 |

這是**免費得到的敘事**——我們沒有寫任何劇本，
只是讓玩家在登記時做了一個選擇，三種文明就自己長出來了。
然後在秋季，速度最快的、最有錢的、最能打的三群人撞在一起。

**平衡風險**：若某一區在第 3 週明顯壓過另外兩區，代表遺跡增益失衡。
驗證條件：三個陣營在遊戲月 9（D9）的總戰力極差 **< 25%**（見 `11` §10）。

## 2. 遺跡控制機制

### 2.1 三階段

```
階段〇：封印 SEALED（春季，遊戲月 1–3 / 真實日 D0–D3）
  遺跡不可進入、不可攻擊。地圖上顯示倒數。
  → 保證賽季有完整的發育期，杜絕開局衝遺跡的速攻流

階段一：沉睡 DORMANT（夏季起，遊戲月 4 / 真實日 D3）
  遺跡解封，由 PvE「遺跡守衛」佔據（固定難度，見 §2.4）
  可以攻打守衛，但無法佔領，也不產出遺物

階段二：甦醒 AWAKENED（守衛被清空後）
  ★ 守衛一旦清空就永不重生。此後遺跡完全靠玩家駐軍守住。
  任何聯盟可派部隊「駐防 Garrison」累積佔領進度

階段三：控制 CONTROLLED
  某聯盟佔領進度達 100%，取得控制權
  開始產出遺物、給予聯盟增益
  其他聯盟可派兵攻擊駐軍；駐軍被打空後進度歸零並重回階段二
```

**階段〇 封印**是為 12 天賽季新增的。沒有它，開局就衝遺跡會成為最優解，
整個發育與地緣經營的前三天會被跳過。封印在夏季第一天（D3）準時解除，
時間公開，所有人可以據此規劃。

### 2.2 佔領進度

```
每分鐘進度變化 = (我方駐軍人口 − 他方駐軍人口總和) / 遺跡容量 × 100 × 2.0%

遺跡容量 = 3,000 人口

滿足以下條件才累積進度：
  - 該遺跡 9 格中，我方是唯一有駐軍的聯盟；否則進入「爭奪 CONTESTED」，
    進度凍結，雙方駐軍每 5 分鐘自動交戰一輪直到一方清空
```

以 3,000 人口滿駐防計算，從 0% 到 100% 需要 **50 分鐘**。
足夠長，讓對手有時間集結反攻；足夠短，讓一次成功的遠征在幾小時內看到結果。

### 2.3 ★ 守住比打下來難

**遺跡的難度不在 PvE 守衛，在其他玩家。**
守衛是固定難度、清一次就沒了；玩家的反攻永遠不會停。

| 機制 | 值 |
| --- | --- |
| 維持控制的**最低駐軍** | **1,500 人口** |
| 低於門檻時的衰減 | 進度每分鐘 **−1.0%**（約 100 分鐘掉光） |
| 駐軍全滅 | 進度立即歸零，遺跡回到 AWAKENED |
| 遺跡駐軍的糧耗 | 由派出方持續支付，**不受遺跡增益減免** |

**同時控制三座 = 至少 4,500 人口釘在地圖上**——而那只是不掉進度的下限。
要真正守得住反攻，實務上每座需要 4,000–6,000 人口，
三座合計 12,000–18,000。對一個 40 人聯盟而言，這是全軍的一半以上。

於是：

- 本土必然空虛 → 其他聯盟的反擊窗口是真實存在的
- 遠征軍的糧耗持續燒 → **冬季來臨時，駐守遺跡的軍隊會最先餓死**（見 `14` §3）
- 領先者必須在秋季結束前拿下三座並撐過 6 小時，否則冬天會把他們拖垮

### 遺跡的歸屬在秋天就決定了

駐軍不是憑空存在的——它受**區域軍隊容納上限**約束（見 `16` §2）。
遺跡所在區域能養多少兵，取決於你在那裡建了多少東西：

```
秋季（×1.3）在遺跡區建了 30 格領土 + 3 座 Lv3 前哨營：
  容量 = (2,000 + 30×150 + 9×800) = 13,700 → 秋季 17,810、冬季 8,220
  → 冬季仍撐得住 3,000 遺跡駐軍 + 5,000 野戰軍

挑戰者在該區毫無建設：
  容量 = 2,000 → 冬季 1,200
  → 連圍城都做不到
```

**所以秋季大會戰的真正目標不是「拿下遺跡」，是「在遺跡周圍蓋出能撐過冬天的補給網」。**
早點拿到遺跡不等於贏；沒把基礎建設鋪好的，冬天守不住。
而冬天才想去搶的，根本推不動。

冬天只是驗收。

「拿下遺跡」是一個瞬間；「守住遺跡」是一場消耗戰。
賽季的勝負決定在後者。

### 2.4 遺跡軍團：固定難度，但會成長並主動出擊

> **完整規格見 [`17-ruin-legions.md`](17-ruin-legions.md)。** 本節只摘要。

| 遺跡 | 基礎人口（解封時） | 組成 |
| --- | --- | --- |
| 灰燼尖塔 | 8,000 | 弓手為主（高防） |
| 沉沒穹窖 | 10,000 | 長矛兵 + 重騎兵混編 |
| 鐵之搖籃 | 12,000 | 精銳混編 |

**遺跡軍團不是靜態的 PvE 障礙，而是第三方勢力**：

```
軍團人口 = 基礎 × 1.15^(當前遊戲月 − 4)     ← 每遊戲月成長 15%

春 封印  → 夏 固守  → 秋 對外擴張  → 冬 四處征伐
```

- **秋季**：每 6 小時派出拓殖隊佔領土地、建立哨所、攻擊相鄰玩家領土
- **冬季**：每 4 小時向區域內玩家據點發動攻擊（規模上限 3,000 人口）
- **你不清掉它，它會來清你。** 這是讓用兵高峰落在秋冬的主要引擎
- **玩家控制該遺跡後，該軍團行為立即永久停止**

**軍團採固定難度**，成長曲線預先定義、公開可查、
**與玩家實力無關**——不隨全服戰力、真人比例或任何其他變數調整。

> **為什麼不做動態難度**：動態難度會讓玩家察覺「我變強了但敵人也變強了」，
> 努力感消失——這是社群最痛恨的設計之一。
> 固定值讓玩家可以規劃：「我們湊得到 9,000 人口，可以打尖塔了」。
> 若實測發現數值不合適，**由營運手動調整並公告**，
> 只在賽季之間生效（見 `12-open-questions.md` B9）。
> 透明的手動調整永遠優於隱形的動態難度。

軍團的其他性質：

- **損傷不會回血**，可以多次進攻慢慢磨（適合小聯盟接力）
- 但**成長是乘在當前人口上的**：打掉一半，它從一半繼續長 15%/月
  → **打了一半就放著是最糟的選擇**：付出了代價卻沒阻止它
- **清空後永不重生**——此後遺跡完全靠玩家駐軍守住（見 §2.3）
- 第一個清空的聯盟獲得：遺物 ×200 + 全服公告 + 賽季積分 500
- **趁虛而入**：軍團每派出一波，本體駐軍就少一波。
  秋冬盯著它的出兵節奏發動總攻，是最省力的打法（偵查兵價值大增）

調校目標為在 **遊戲月 4–6（真實日 D3–D6，夏季）** 被首次清空。
若實測落在夏季之外，調整基礎人口或成長率，而非引入動態機制。

## 3. 賽季勝利條件

```
單一聯盟同時控制三座遺跡，並維持 6 小時
  → 賽季結束
```

- 進入「同時控制三座」的瞬間，**全服公告 + 6 小時倒數計時器**出現在所有玩家畫面頂端
- 倒數期間任何一座遺跡失守 → 倒數立即中止並重置
- 這 6 小時是整個賽季的高潮：所有其他聯盟會臨時結盟，發動總攻

> 6 小時（原為 24 小時）：12 天的賽季裡，24 小時佔 8%，太長。
> 6 小時仍足以讓其他聯盟從本土集結遠征軍（最大行軍 8 小時，
> 但實務上會從前哨營出擊），也短到讓倒數本身充滿張力。

### 3.1 期滿結算

若第 **12 日終了**仍無聯盟達成，賽季以積分結算排名（完整公式見 `14` §6）：

```
聯盟賽季積分 = 遺跡控制總時數（真實小時） × 300
             + 成員總領土數 × 2
             + 成員主堡等級總和 × 1
             + 清除遺跡守衛的首殺 × 500
             + 冬季（D9 後）期間仍持有遺跡的每小時 × 200
```

冬季的額外加權確保最後三天的爭奪值得為之流血，
而不是「早點拿到就贏了」。

## 4. 賽季結束與傳承

### 4.1 結束流程

```
賽季結束宣告（提前達成 或 第 12 日終了）
  → 12 小時「終戰期」：地圖凍結，不可攻擊，可自由瀏覽最終版圖與統計
  → 結算榜單與傳承點（總排名 + 真人排名並列，見 15-ai-players.md §2）
  → 地圖歸檔（永久可查看的靜態快照頁面 /seasons/{id}）
  → 玩家於 2 日後進入下一場賽季（登記已在第 11 日開放，見 14 §5）
```

賽季不再「重置」——**每一場都是全新的一場**。
玩家保留的只有傳承點、頭銜與外觀（見 §4.2），
而由於賽季只有 12 天、每 7 天開一場，重新開始的心理成本極低。
這正是短賽季制最大的優勢：**輸掉一場不是輸掉兩個月。**

### 4.2 傳承（Legacy）

跨賽季保留的只有三樣東西，**都不能買**：

| 保留項目 | 說明 |
| --- | --- |
| **傳承點 Legacy Points** | 依賽季表現獲得，可兌換永久加成 |
| **頭銜與徽章** | 「首座遺跡開荒者」「三遺跡征服者」等，顯示在名稱旁 |
| **外觀皮膚** | 賽季限定據點／單位外觀 |

**永久加成上限刻意壓得很低**：全部點滿也只有

- 起始資源 +50%
- 建造速度 +5%
- 研究速度 +5%

老玩家的優勢是**經驗與人脈**，不是數值。新賽季第一天，
一個新人和一個玩了五個賽季的老手，戰力差距不應超過 10%。
這是保護長期伺服器健康最重要的一條線。

## 5. 遺跡相關 UI

| 介面 | 內容 |
| --- | --- |
| 地圖上的遺跡 | 3×3 特殊貼圖，外圈進度環（控制聯盟色），中心圖示依三座各異 |
| 遺跡詳情頁 | 當前控制者、進度、各方駐軍人口、增益列表、歷史控制紀錄時間軸 |
| 全服狀態列 | 常駐顯示三座遺跡的當前控制聯盟（沒有控制者則顯示「甦醒中／沉睡」） |
| 終局倒數 | 全螢幕頂部紅色橫幅 + 剩餘時間，所有玩家可見 |

「全服狀態列」永遠可見這一點很重要：即使一個玩家從沒去過遺跡，
他每天登入都會看到三座遺跡的局勢在變化，賽季的敘事因此對每個人都成立。
