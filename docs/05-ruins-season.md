# 05 · 三座古老遺跡與賽季制

遺跡是 RuinCity 的**終局系統**。它們回答了一個所有長青 SLG 都逃避的問題：
「這場戰爭什麼時候結束？」

## 1. 三座遺跡

三座遺跡在賽季開始時隨機放置（約束見 `01-world-map.md` §4），各佔 3×3 格。
它們機制相同，但提供不同的**聯盟增益**，讓「先搶哪一座」成為戰略決策。

| # | 名稱 | 增益（給控制它的聯盟全體成員） | 遺物產出 |
| --- | --- | --- | --- |
| I | **灰燼尖塔** The Ashen Spire | 全體行軍速度 **+20%** | 12 / h |
| II | **沉沒穹窖** The Drowned Vault | 全體資源產出 **+25%**、地窖保護 **+50%** | 12 / h |
| III | **鐵之搖籃** The Iron Cradle | 全體單位攻擊與防禦 **+12%** | 12 / h |

遺物產出**平均分配**給控制聯盟的所有線上成員（過去 48 小時內登入過者）。
50 人的聯盟每人每小時得 0.24 遺物；10 人的小聯盟每人得 1.2。
→ 小而精的聯盟在遺物人均上有優勢，大聯盟在兵力上有優勢，兩者平衡。

### 為什麼是三座、增益為什麼這樣配

- **灰燼尖塔（速度）**：拿到它的聯盟更容易搶下另外兩座 → 它是「第一優先目標」，
  所以賽季中期的第一場大會戰幾乎必然在這裡發生。
- **沉沒穹窖（經濟）**：續戰能力。長期戰爭中最終決定勝負的。
- **鐵之搖籃（戰力）**：最直接，但也最容易讓局勢一面倒 → 因此加成刻意壓在 12%。

三種增益分別對應「機動 / 經濟 / 戰力」，沒有一座是可以放棄的。

## 2. 遺跡控制機制

### 2.1 三階段

```
階段一：沉睡 DORMANT（賽季第 0 天起）
  遺跡由 PvE「遺跡守衛」佔據，兵力極高（見 §2.4）
  無人可以佔領，也不產出遺物

階段二：甦醒 AWAKENED（守衛被清空後）
  遺跡進入可爭奪狀態
  任何聯盟可派部隊「駐防 Garrison」累積佔領進度

階段三：控制 CONTROLLED
  某聯盟佔領進度達 100%，取得控制權
  開始產出遺物、給予聯盟增益
  其他聯盟可派兵攻擊駐軍，打空後進度歸零並重回階段二
```

### 2.2 佔領進度

```
每分鐘進度變化 = (我方駐軍人口 − 他方駐軍人口總和) / 遺跡容量 × 100 × 0.5%

遺跡容量 = 3,000 人口

滿足以下條件才累積進度：
  - 該遺跡 9 格中，我方是唯一有駐軍的聯盟；否則進入「爭奪 CONTESTED」，
    進度凍結，雙方駐軍每 10 分鐘自動交戰一輪直到一方清空
```

以 3,000 人口滿駐防計算，從 0% 到 100% 需要 **200 分鐘（約 3.3 小時）**。
足夠長，讓對手有時間集結反攻；足夠短，讓一次成功的遠征在同一天內看到結果。

### 2.3 控制權衰減

控制中的聯盟若駐軍低於 **500 人口**，進度每分鐘 −0.3%。
→ 拿下遺跡不是終點，必須**持續駐軍**。這讓遺跡成為一個長期的兵力黑洞，
控制三座遺跡意味著把 9,000 人口的兵力釘在地圖上，本土會空虛。
其他聯盟因此有反擊的窗口，勝利不會是輕鬆的。

### 2.4 遺跡守衛（PvE 開荒）

| 遺跡 | 守衛人口 | 組成 |
| --- | --- | --- |
| 灰燼尖塔 | 8,000 | 弓手為主（高防） |
| 沉沒穹窖 | 10,000 | 長矛兵 + 重騎兵混編 |
| 鐵之搖籃 | 12,000 | 精銳混編 |

守衛**不會回血**，可以多次進攻慢慢磨。
第一個清空守衛的聯盟獲得一次性獎勵：遺物 ×200 + 全服公告。
→ 開荒本身就是一場聯盟間的競速。

守衛設計上約需 **3–5 個中型聯盟等級的兵力**，預期在賽季第 3–4 週被清空。

## 3. 賽季勝利條件

```
單一聯盟同時控制三座遺跡，並維持 24 小時
  → 賽季結束
```

- 進入「同時控制三座」的瞬間，**全服公告 + 24 小時倒數計時器**出現在所有玩家畫面頂端
- 倒數期間任何一座遺跡失守 → 倒數立即中止並重置
- 這 24 小時是整個賽季的高潮：所有其他聯盟會臨時結盟，發動總攻

### 3.1 保底結束

若第 **8 週結束**時仍無聯盟達成，賽季以積分結算：

```
聯盟賽季積分 = 遺跡控制總時數 × 100
             + 成員總領土數 × 2
             + 成員主堡等級總和 × 1
             + 清除遺跡守衛的首殺 × 500
```

## 4. 賽季結束與傳承

### 4.1 結束流程

```
賽季結束宣告
  → 24 小時「終戰期」：地圖凍結，不可攻擊，可自由瀏覽最終版圖與統計
  → 結算榜單與傳承點
  → 地圖歸檔（永久可查看的靜態快照頁面 /seasons/{id}）
  → 新賽季以新 seed 生成，所有玩家重置為 Lv1 主堡
```

### 4.2 傳承（Legacy）

跨賽季保留的只有三樣東西，**都不能買**：

| 保留項目 | 說明 |
| --- | --- |
| **傳承點 Legacy Points** | 依賽季表現獲得，可兌換永久加成 |
| **頭銜與徽章** | 「首座遺跡開荒者」「三遺跡征服者」等，顯示在名稱旁 |
| **外觀皮膚** | 賽季限定據點／單位外觀 |

**永久加成上限刻意壓得很低**：全部點滿也只有

- 起始資源 +50%
- 建造速度 +5%
- 研究速度 +5%

老玩家的優勢是**經驗與人脈**，不是數值。新賽季第一天，
一個新人和一個玩了五個賽季的老手，戰力差距不應超過 10%。
這是保護長期伺服器健康最重要的一條線。

## 5. 遺跡相關 UI

| 介面 | 內容 |
| --- | --- |
| 地圖上的遺跡 | 3×3 特殊貼圖，外圈進度環（控制聯盟色），中心圖示依三座各異 |
| 遺跡詳情頁 | 當前控制者、進度、各方駐軍人口、增益列表、歷史控制紀錄時間軸 |
| 全服狀態列 | 常駐顯示三座遺跡的當前控制聯盟（沒有控制者則顯示「甦醒中／沉睡」） |
| 終局倒數 | 全螢幕頂部紅色橫幅 + 剩餘時間，所有玩家可見 |

「全服狀態列」永遠可見這一點很重要：即使一個玩家從沒去過遺跡，
他每天登入都會看到三座遺跡的局勢在變化，賽季的敘事因此對每個人都成立。
