# 10 · 開發路線圖

目標：**M0–M6 完成後即可開啟賽季 0（封測）**。
每個里程碑都以「可玩」為驗收標準，不做只有後端沒有畫面的階段。

---

**產出**：能跑起來的空殼 + CI

- [ ] `create-next-app`（Next.js 15 / App Router / TypeScript strict / Tailwind v4）
- [ ] Drizzle ORM + Neon Postgres 連線、migration 流程
- [ ] Auth.js v5（Google OAuth + 訪客帳號）
- [ ] 專案結構依 `07-tech-architecture.md` §7 建立
- [ ] `/lib/game/balance/` 數值表（從 `11-balance-tables.md` 轉為 TypeScript 常數）
- [ ] Vitest + Playwright 設定；GitHub Actions（typecheck / lint / test）
- [ ] Vercel 部署 + preview environment

**驗收**：能註冊登入，看到一個寫著「RuinCity」的空白頁。

## M1 · 世界與地圖渲染

**產出**：能看、能縮放、能移動的 500×500 地圖

- [ ] `scripts/generate-map.ts`：seed → 地形 → 64 個 chunk 二進位檔
- [ ] 遺跡放置演算法 + 約束驗證
- [ ] 三分天下：以行軍成本距離做 Voronoi 分割成三個陣營區域
- [ ] 出生點批次分配：環帶劃分 + Poisson-disk sampling + 同行小隊群集
- [ ] **五項公平性驗證**，未通過自動換 seed 重跑（見 `13` §3）
- [ ] PixiJS v8 場景：terrain / territory / structure / march / overlay 五層
- [ ] Texture atlas 與地形貼圖（先用色塊佔位，美術後補）
- [ ] 視野剔除 + sprite 物件池
- [ ] 三級縮放（L1/L2/L3）與手勢操作
- [ ] `/api/map` 與 `/api/map/overview`
- [ ] IndexedDB 快取地形 chunk

**驗收**：在手機上流暢平移／縮放整張 500×500 地圖，FPS ≥ 50，
首次載入 < 3 秒。地圖上能看到三座遺跡與自己的出生位置。
以 1,500 名模擬玩家跑分配，五項公平性驗證全數通過，且總耗時 < 60 秒。

## M2 · 據點、經濟與建造

**產出**：能發育的單人遊戲

- [ ] `players` / `base_slots` / `player_resources` schema
- [ ] 惰性結算引擎 `settlePlayer()`
- [ ] `events` 表 + `BUILD_DONE` 事件與結算
- [ ] 核心 2×2 建築系統（主堡 + 7 選 3）、升級、拆除
- [ ] **核心建造佇列（永遠 1 條，主堡與 B/C/D 共用）** 與領土設施佇列（1–4 條）分離
- [ ] 領土佔領：`claimTile`、連通性 BFS、ISOLATED 狀態與過期
- [ ] 拓荒成本三重遞增（資源／民兵／時間），同時拓荒上限 = 領土佇列數
- [ ] 外部設施建造與產出計算
- [ ] 資源上限、溢出、地窖保護量計算
- [ ] 據點畫面 UI + 建造佇列

**驗收**：新玩家可以從 Lv1 主堡發育到 Lv10、佔領 30 塊領土，
關掉分頁一小時後回來資源正確累積，數字與 `11-balance-tables.md` 一致。
**取捨檢驗**：三位測試者從同一起點出發、走不同路線（衝主堡／衝兵營／鋪設施），
第 7 天應長成三種明顯不同的狀態（見 `03` §7.3）。

### M5b · 賽季登記系統

- [ ] 賽季生命週期狀態機（登記期 → 封盤期 → 進行中 → 終戰期 → 賽間期）
- [ ] 登記頁：陣營選擇（即時名額顯示）、出生帶選擇、同行小隊代碼
- [ ] 陣營硬性名額 `⌈N/3⌉`，額滿關閉
- [ ] 封盤期批次作業：地圖生成 → 分配 → 驗證 → 公布預覽
- [ ] 出生點公布頁（自己的座標、鄰居、離遺跡距離、公平性驗證數值公開）
- [ ] T=0 一次性寫入所有玩家的初始狀態
- [ ] 中途加入流程（T+3 緩衝名額、T+3~14 邊陲帶 + 後進者補給、T+14 關閉）
- [ ] 未登入出生點回收（T+24h）
- [ ] 觀戰模式（等待下賽季的玩家可看地圖與排行榜）

**驗收**：跑一次壓縮版賽季（時間 ×20 加速），
能完整走完「登記 → 封盤分配 → 同時開賽 → 開荒 → 爭奪 → 三遺跡同控 →
倒數 → 結束 → 歸檔 → 下賽季登記」。
以 1,500 筆模擬登記執行封盤作業，五項公平性驗證全數通過。
