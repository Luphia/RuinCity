# 17 · 遺跡軍團

> **設計變更紀錄**：原設計中遺跡守衛是**靜態的 PvE 障礙**——
> 固定人口、坐在遺跡裡等人來清。清掉就沒了。
>
> 現改為：**遺跡軍團會隨時間成長，秋季開始向外擴張，冬季四處主動進攻。**
>
> 這把遺跡從「一個目標」變成「**第三方勢力**」，
> 而且是一個**你不處理它、它就會來處理你**的勢力。
> 它也是讓用兵高峰落在**秋冬**的主要引擎。

## 1. 核心概念：三顆定時炸彈

地圖上的三座遺跡各駐紮一支**遺跡軍團 Ruin Legion**。

```
你在夏季清掉它  → 遺跡歸你，軍團永遠消失，你得到增益與遺物
你沒清掉        → 它會一直長大，秋天開始吃你的領土，冬天直接來打你家
```

**沒有第三種結果。** 遺跡不會安靜地待在那裡等你有空。

這徹底改變了夏季的優先順序：清遺跡不再是「拿獎勵」，
而是「**拆炸彈**」。而且三座都得拆——你拆了一座，另外兩座還在長。

## 2. 軍團成長

軍團從**解封當下**（遊戲月 4 / 真實日 D3）開始成長：

```
軍團人口 = 基礎人口 × 1.15^(當前遊戲月 − 4)
```

| 遊戲月 | 真實日 | 倍率 | 灰燼尖塔 | 沉沒穹窖 | 鐵之搖籃 |
| --- | --- | --- | --- | --- | --- |
| 4（解封） | D3 | 1.00 | 8,000 | 10,000 | 12,000 |
| 5 | D4 | 1.15 | 9,200 | 11,500 | 13,800 |
| 6 | D5 | 1.32 | 10,600 | 13,200 | 15,900 |
| **7（秋）** | D6 | 1.52 | 12,200 | 15,200 | 18,200 |
| 8 | D7 | 1.75 | 14,000 | 17,500 | 21,000 |
| 9 | D8 | 2.01 | 16,100 | 20,100 | 24,100 |
| **10（冬）** | D9 | 2.31 | 18,500 | 23,100 | 27,700 |
| 11 | D10 | 2.66 | 21,300 | 26,600 | 31,900 |
| 12 | D11 | 3.06 | 24,500 | 30,600 | 36,700 |

### 這仍然是「固定難度」

成長曲線是**預先定義、公開可查、與玩家實力無關**的。
它不是動態難度——不會因為你變強而變強。

玩家可以精確規劃：「第 6 月要打鐵之搖籃，我們需要湊 16,000 人口。
拖到第 9 月就要 24,000，那時我們湊不出來。」

**時間壓力來自時鐘，不是來自你**。這是與動態難度的關鍵區別
（見 `12-open-questions.md` B4）。

### 損傷不會回復，但成長會繼續

- 軍團被打掉的兵力**不會回血**——可以多次進攻慢慢磨
- 但成長是**乘在當前人口上**的：你打掉一半，它從一半開始繼續長
- 所以**打了一半就放著是最糟的選擇**：你付出了代價，卻沒有阻止它

## 3. 四季行為

| 季 | 遊戲月 | 行為 |
| --- | --- | --- |
| 春 · 荒芽 | 1–3 | **封印**。不可進入、不可攻擊。軍團在內部成形 |
| 夏 · 焦土 | 4–6 | **固守**。只待在遺跡的 3×3 範圍內，不主動出擊 |
| 秋 · 豐鏽 | 7–9 | **擴張**。向外佔領土地、建立哨所、攻擊相鄰的玩家領土 |
| 冬 · 長夜 | 10–12 | **征伐**。向所在區域與相鄰區域的玩家據點主動發動攻擊 |

> **玩家控制該遺跡後，該軍團的所有行為立即永久停止。**
> 拆掉的炸彈不會再響。

### 3.1 秋季：擴張

```
每 6 小時，遺跡派出一支「拓殖隊」：
  目標選擇（依序）：
    1. 與遺跡勢力範圍相鄰的中立空地 → 佔領，建立「遺跡哨所」
    2. 若無中立空地相鄰 → 攻擊相鄰的玩家領土格

  出兵規模 = 當前軍團人口 × 8%，單次上限 3,000 人口
  出兵後該部分兵力離開遺跡本體（遺跡本體防禦相應下降）
```

**遺跡哨所 Ruin Outpost**：

- 佔 1 格，駐軍 = 派出的拓殖隊
- 成為進一步擴張的跳板（下一波從哨所而非遺跡出發）
- 產生固定防禦 `400`
- **玩家可以攻打並摧毀它**，該格回歸中立
- 摧毀哨所是把遺跡勢力推回去的唯一方法

秋季結束時，一座未被清除的遺跡通常已擴張出 **8–14 格**的勢力範圍，
並吃掉附近玩家 3–6 格的領土。

### 3.2 冬季：征伐

```
每 4 小時，遺跡向以下範圍內隨機選擇一個目標發動攻擊：
  範圍 = 遺跡所在區域 + 所有相鄰區域

  目標權重：
    領土最多的玩家   權重 ×3
    距離最近的玩家   權重 ×2
    其餘玩家         權重 ×1
    （新手與弱者不會被優先選中——遺跡追逐的是規模）

  目標類型：核心據點 60% / 領土格 40%

  出兵規模 = 當前軍團人口 × 14%，單次上限 3,000 人口
```

以第 11 月的鐵之搖籃（31,900 人）計算：
單次出兵 3,000 人口（觸及上限），**每 4 小時一次**。
一天六波，全部砸向同一個區域的玩家們。

### 3.3 為什麼這造就秋冬用兵高峰

| 季 | 玩家用兵的原因 |
| --- | --- |
| 春 | 幾乎沒有（人口剛起步、無建設、遺跡封印） |
| 夏 | 領土衝突 + **拆炸彈的競速** |
| **秋** | 大會戰 + **擋住三支正在吃地的軍團** |
| **冬** | 生存決戰 + **每 4 小時一波，共三支軍團同時來襲** |

冬季的戰場密度是全季最高的：
玩家對玩家的決戰、遺跡軍團的六波日常進攻、
以及斬首戰（見 `06-alliance.md` §4）——**同時發生**。

而你的糧食產出只剩 55%。

## 4. 意外的效果：冬季的臨時同盟

遺跡軍團**無差別攻擊區域內所有玩家**，不管你們彼此是不是敵人。

於是冬季會自然出現一種局面：
兩個打了整個秋天的敵對聯盟，發現同一支軍團正在輪流錘他們——
於是他們停火，一起把哨所拔掉。

我們**沒有設計任何外交系統**（v1 無 NAP、無宣戰，見 `06` §2），
但共同的威脅會逼出真實的談判。這是整份企劃裡我最喜歡的一個湧現行為。

## 5. 玩家的應對手段

| 手段 | 說明 |
| --- | --- |
| **夏季清空** | 最優解。成本最低（軍團最小），且永久解除威脅 |
| **摧毀哨所** | 把遺跡勢力推回去，減緩擴張。哨所被毀後該格回歸中立 |
| **搶先佔領** | 軍團出兵後遺跡本體防禦下降 → 秋冬是「趁虛而入」的窗口 |
| **建牆囤兵** | 冬季死守。可行但被動，且你的糧食在燒 |
| **搬家** | 放棄邊緣領土，把版圖收縮到遺跡打不到的區域 |

### ★ 趁虛而入

這是秋冬最重要的戰術：

```
遺跡每派出一波，本體駐軍就減少一波的量。
第 11 月的鐵之搖籃有 31,900 人，但若剛連續派出三波（9,000 人在外），
本體只剩 22,900 —— 而你原本要打 31,900。
```

聰明的聯盟會**盯著遺跡的出兵節奏**，在它兵力最空虛時發動總攻。
遺跡的當前本體駐軍在偵查後可見（誤差 ±10%），
所以偵查兵在秋冬的價值大幅提升。

## 6. 資料模型

```sql
ALTER TABLE ruins
  ADD COLUMN legion_population NUMERIC(10,0) NOT NULL,  -- 當前本體駐軍
  ADD COLUMN legion_base       NUMERIC(10,0) NOT NULL,  -- 基礎人口（8k/10k/12k）
  ADD COLUMN last_sortie_at    TIMESTAMPTZ;             -- 上次出兵時間

-- 遺跡哨所以 tiles.kind = 'RUIN_OUTPOST' 表示，
-- 駐軍存在 garrisons 表（owner_id 指向該遺跡的系統 player）
```

每座遺跡對應一個 `is_ai = true`、`ai_persona = 'RUIN_LEGION'` 的系統 player，
讓它的部隊、行軍、戰鬥完全走**與真人相同的引擎與驗證路徑**。
不開後門——這也讓遺跡軍團成為整個戰鬥系統的壓力測試。

### 事件

| 事件 | 頻率 | 說明 |
| --- | --- | --- |
| `LEGION_GROWTH` | 每遊戲月（24 真實小時） | 套用 ×1.15 |
| `LEGION_SORTIE` | 秋季每 6h、冬季每 4h | 選目標、派兵、排 `MARCH_ARRIVE` |
| `RUIN_UNSEAL` | 一次（D3） | 解封 |

## 7. 平衡驗證

- [ ] 三座遺跡中，**至少 1 座**在夏季（遊戲月 4–6）被清空的賽季比例 **≥ 70%**
- [ ] 三座**全部**在夏季被清空的比例 **< 15%**（否則軍團機制形同虛設）
- [ ] 秋季結束時，未清除的遺跡平均擴張出 **8–14 格**勢力範圍
- [ ] 冬季由遺跡軍團發起的戰鬥，佔冬季總戰鬥次數 **25–40%**
      （太低 = 威脅不足；太高 = 淹沒了玩家間的決戰）
- [ ] 冬季有 **≥ 30%** 的玩家至少被遺跡軍團攻擊過一次
- [ ] 「趁虛而入」確實發生：秋冬期間對遺跡本體的成功攻擊中，
      **≥ 50%** 發生在遺跡剛出兵後的 2 小時內
- [ ] 全 AI 賽季中，**遺跡軍團不會被清空**，且不會導致 AI 大規模滅絕
      （AI 應能守住核心據點，領土可以被吃）
