### 由 A7 衍生的設計

- **遊戲曆法**：1 真實日 = 1 遊戲月 = 30 遊戲日；介面顯示「廢曆 41 年 · 3 月 12 日」
- **四季效應**（每季 3 遊戲月 = 3 真實日），讓時間有機械意義而非只是風味：
  春 產出 ×1.10 → 夏 標準 → 秋 產出 ×1.20、招兵 ×1.15 → **冬 產出 ×0.70、糧耗 ×1.30、行軍 ×1.25**
- **冬季是收束機制**：多數玩家糧食收支轉負，養不起不打仗的軍隊，龜縮到期滿不再可行
- **遺跡封印**：春季（D0–D3）不可進入，杜絕開局速攻，保證發育期
- **時間係數** `TIME_SCALE = 4`（生產時間 ÷4、資源流速 ×4）、`MARCH_SCALE = 2`（速度 ×2）
  行軍只加速 2 倍而非 4 倍，否則預警窗口會小到讓「可離線」支柱垮掉
- **預警改為比例制** `行軍總時間 × 40%`，clamp [3 分, 30 分]；哨塔 60%
- 勝利維持 24h → **6h**；終戰期 24h → **12h**；聯盟上限 50 → **30 人**
- **玩家個人循環 14 天**：D11（自己賽季的最高潮）開放下一場登記，
  和並肩作戰的人一起報名——這是短賽季制唯一的留存機會
- **任何時刻有兩個賽季同時運行**（重疊 5 天），一位玩家同時只能參與一場

### 由 A8 衍生的設計

- N 已知 → **廢除上一版的動態名額機制**，陣營名額直接固定 200/陣營
- 600 人在 250,000 格上太稀疏 → 不縮小地圖，改為**集中在三座遺跡周圍的環帶**
  （每陣營 ~33,300 格、167 格/人），其餘 60% 為荒野
- **邊陲帶的定位翻轉**：離自家遺跡最遠 = 離敵對陣營最近。
  上一版把邊陲設為「最安全」是錯的
- **取消中途加入**：12 天賽季裡晚一天就是晚一個月，補償只是自欺欺人。
  可行的前提是每 7 天就有新場（最長等 7 天，平均 3.5 天）
- **AI 誠實原則**：`◈` 前綴標示、公開人數比、公開行為腳本、
  排行榜同時顯示總排名與真人排名、AI 不可組聯盟也不可觸發勝利
- **AI 依固定腳本曲線發育**（與 A9 同一原則），不追蹤真人中位數
- **AI 託管離線玩家**（未首登 6h／連續未登入 48h），資產保留、回歸即歸還

### 由 A5 衍生的設計

- **賽季生命週期**（數值後由 A7 更新）：登記期 → 封盤期 → 全員同時開戰 → 終戰期
- 登記時做三個不可更改的選擇：**陣營**（三選一）、
  **出生帶**（前線／中原／邊陲）、**同行小隊**（≤8 人）
- 陣營名額採**動態容量** `max(20, ⌈總登記數 × 1.08 / 3⌉)`，
  解掉「名額 = N/3 但 N 尚未確定」的雞生蛋問題，
  並在數學上把單一陣營佔比鎖在 28%–36% 且保證不死鎖
- 地圖依三座遺跡做 Voronoi 分割（用行軍成本距離，山脈成為天然邊界）
- 出生點以 Poisson-disk sampling 產生，需通過 **5 項公平性驗證**才採用，
  驗證數值在封盤期公開
- 三座遺跡增益不同 → 選陣營等於宣告玩法 → **三個區域自然演化出不同性格**
- ~~建議登記上限 1,500 人~~ → 由 **A8** 改為每場固定 600 人
- ~~中途加入 T+14 天後關閉~~ → 由 **A7/A8** 改為完全不開放中途加入

### 由 A6 衍生的設計

- 核心佇列（主堡 + B/C/D 共用）**永遠 1 條，不隨等級／科技／付費增加**
  → 「每一分鐘你在升主堡，就是一分鐘你沒有在升兵營」
- 主堡等級改為提升**領土設施佇列**（`1 + ⌊主堡等級/10⌋`，1–4 條）
- 拓荒成本三重遞增：資源 `×(1 + 領土/15)`、民兵 `5 + ⌊領土/10⌋`、時間 `×(1 + 領土/20)`
  → 擴張到 120 塊領土累積吃掉約 1,300 人口，**擴張本身在跟軍隊搶人口**
- 新增「取捨強度檢查」四項驗證條件（見 `03` §7.4 與 `11` §10）

### 由 A2 衍生的設計

- 核心 2×2 只有 4 格，A 格固定主堡，B/C/D 從 7 種建築中三選三 → 流派分化
- 領土容量 = `4 × 主堡等級`
- 領土必須與核心**四連通**，斷連即 ISOLATED，24 小時後自動放棄
  → 「切細頸」成為領土戰的核心戰術
- 搶領土需要兩趟行軍（打垮 + 拓荒），成本高於劫掠 → 控制地圖變動頻率

## B. 待決議（需在對應里程碑前確認）

### ~~B1 · 一位使用者能否有多個賽季並行？~~ — ✅ 已由 A7 決定並關閉

**伺服器端必然並行**：12 天賽季 + 7 天輪替 → 任何時刻有兩場同時運行（重疊 5 天）。
schema 已支援（所有遊戲資料以 `season_id` 分割）。

**玩家端：同時只能參與一場。**

12 天的賽季需要專注，分裂注意力會讓兩場都玩不好，
也讓「這場戰爭對我很重要」的感覺消失。
UI 因此不需要伺服器選擇畫面——玩家只會看到「你目前的賽季」與「下一場登記」。

真人玩家因此自然分成**兩個交錯的世代**（奇數場／偶數場），各自 14 天循環。

> 若未來要對硬核玩家開放同時多場，應作為明確的成就或付費解鎖，而非預設。

### ~~B4 · 遺跡守衛強度是否該隨全服總戰力動態調整？~~ — ✅ 已由 A9 決定並關閉

**決定：固定難度，永不動態調整。**

動態難度會讓玩家察覺「我變強了但敵人也變強了」，努力感消失——
這是社群最痛恨的設計之一。固定值讓玩家可以規劃：
「我們湊得到 9,000 人口，可以打尖塔了」。

若實測發現數值不合適，**由營運手動調整並公告，只在賽季之間生效**（見 B9）。
透明的手動調整永遠優於隱形的動態難度。

同一原則也套用到 AI 玩家的發育曲線（`15` §4）：固定腳本，公開可查。

**配套**：難度從 PvE 移到 PvP——守衛清空後**永不重生**，
遺跡此後完全靠玩家駐軍守住（門檻 1,500 人口，實務上需 4,000–6,000）。
「拿下遺跡」是一個瞬間，「守住遺跡」是一場消耗戰。

**12 天賽季的調校目標**：守衛在遊戲月 4–6（D3–D6，夏季）被首次清空。
若實測落在夏季之外，調整守衛人口而非引入動態機制。

### ~~B5 · 單人退遊後的據點處置~~ — ✅ 已由 A8 解決並關閉

改為 **AI 託管**（見 `15-ai-players.md` §6）：

```
未首次登入 6 小時       → AI（Settler）接管
賽季中連續 48 小時未登入 → AI（Settler）託管，玩家回歸即歸還
```

比原方案（領土逐日歸還中立）好的地方：**地圖密度不會下降**
（600 人是設計常數），而回歸的玩家還有完整的家可回。
託管以 `◈託管` 明確標示，且**不提供無敵**——否則會變成離線保護的漏洞。

### B6 · 全服聊天頻道要不要做？ — 需在 M4 前決定

**支持**：新玩家找聯盟的主要管道；賽季敘事的發生地（嘴砲、宣戰、外交）。
**反對**：需要審核與管理成本；容易變成洗版與騷擾溫床。

**傾向**：做，但加上：發言需主堡 Lv5、每人每 3 分鐘 1 則、檢舉與自動禁言、
以及一個獨立的「招募」子頻道分流。

### B7 · 手機橫向模式要支援嗎？ — 需在 M1 前決定

地圖在橫向可見範圍大得多，硬核玩家會想要。
但整套 UI（底部 tab、bottom sheet、行動輪盤）都是為直向設計的。

**傾向**：**v1 只鎖直向**，但地圖畫面單獨允許橫向（進入地圖時解鎖旋轉，
離開時鎖回直向）。這是成本最低、收益最高的折衷。

### ~~B8 · 賽季之間要間隔多久？~~ — ✅ 已由 A7 決定並關閉

**玩家的間隔為 2 天**（賽季 D12 結束 → D14 進入下一場）。
伺服器則每 7 天開新場，兩場重疊 5 天。

關鍵設計：**下一場的登記在玩家自己賽季的第 11 日開放**——
也就是他的戰爭最高潮的那一天。這是把單場的社群關係
接續到下一場最自然的時機，也是短賽季制唯一的留存機會。

### B9 · 數值熱更新的邊界在哪？ — 需在 M6 前決定

`/lib/game/balance` 設計為可熱更新，但如果賽季進行中改動兵種攻擊力，
已經投資在該兵種上的玩家會強烈反彈。

**傾向**：訂立明文規則並公告：
- 賽季進行中**只能**調整：PvE 營地強度、遺跡守衛強度、營地刷新率
- 影響 PvP 平衡的數值（兵種、戰鬥公式、建築成本）**只在賽季之間調整**
- 例外：確認為 bug 或嚴重破壞平衡的漏洞，可緊急修正並補償受影響玩家

### B10 · 登記灌水防治 — 需在 M5 前決定

假登記會佔掉陣營名額，並讓地圖出現大量從未上線的空洞出生點，
破壞「同一條起跑線」的公平性與地圖密度。

**傾向**：登記需 email 驗證；**T+24 小時仍未登入者，出生點自動回收為中立空地**
（該格變回一般地形，其起始資源不發放）。回收數量在遊戲內公告，維持透明。

---

### B11 · 陣營名額額滿後的處理 — 需在 M5 前決定

三座遺跡增益不同，理論上會有一個「當下版本最強」的選項先額滿。

**候選方案**：
1. 不加開，額滿即關（稀缺是設計的一部分）
2. 動態放寬 5–10% 緩衝
3. 抽籤制（登記期結束後統一抽，而非先到先得）

**傾向**：方案 1，但登記開放時間需**提前 48 小時公告到分鐘**，
讓所有人有公平的搶名額機會。方案 3 雖然更公平，
但失去了「登記當下就要做決定」的緊張感，也讓社群無法即時看到局勢形成。

**觀察指標**：若連續兩個賽季都是同一個陣營先額滿，代表該遺跡增益過強，
應在賽間期調整（符合 B9 的熱更新規則）。

### B12 · 同行小隊代碼是否公開可搜尋？ — 需在 M5 前決定

### B13 · 核心佇列只有 1 條，會不會讓後期太慢？ — 需在 M2 實測

主堡 Lv25→30 單次升級就要 21 小時到 2 天 20 小時。
若同時還想升兵營與城牆，後期可能會出現「一週只做得了兩件事」的停滯感。

**候選緩解**（依破壞取捨的程度由輕到重）：
1. 不緩解——停滯感正是後期資源該投向軍隊與遺跡而非建築的訊號
2. 提供「加速」道具，僅能用於**已在佇列中**的項目，且不可付費購買（PvE 掉落）
3. 主堡 Lv25 後開放第二條核心佇列

**傾向**：方案 1，並在 M2 實測後才決定是否需要方案 2。
**方案 3 絕對不做**——它會在最需要取捨的階段把取捨拿掉，
與 A6 的整個設計意圖相反。

### B14 · 12 天賽季裡，傳承點累積是否過快？ — 需在 M5 前決定

玩家每 14 天完成一場賽季 → 一年約 26 場。
原設計的傳承加成上限（起始資源 +50%、建造 +5%、研究 +5%）
會在 5–8 場（約 3 個月）內點滿。

**傾向**：**維持現有上限，不因場次變多而提高。**
上限的存在就是為了保證「新人與老手在第一天的戰力差距 < 10%」，
點滿之後傳承的意義轉為**頭銜與外觀**（收藏而非戰力）。
若擔心老玩家失去目標，應增加**外觀與稱號的深度**，而不是提高數值上限。

### B15 · 冬季懲罰會不會把玩家凍住而不是逼出來？ — 需在 M2/M5 實測

冬季（產出 ×0.70、糧耗 ×1.30）的意圖是逼迫決戰。
但若懲罰過重，玩家可能反而**解散軍隊自保**，導致最後三天一片死寂——
與設計意圖完全相反。

**驗證條件**（見 `11` §10）：
- D9 進入冬季後，全服 **≥ 60%** 的玩家糧食收支轉負（否則冬天沒效果）
- D9–D12 的戰鬥次數 **≥ 秋季同期的 80%**（否則冬天把人凍住了）

**調整旋鈕**（依優先順序）：
1. 先調糧耗（×1.30 → ×1.15），保留產出懲罰
2. 再調產出（×0.70 → ×0.80）
3. 最後才考慮縮短冬季（3 天 → 2 天）

---

### B16 · 兩場賽季同時運行，數值熱更新如何隔離？ — 需在 M5 前決定

短賽季最大的營運紅利是**迭代週期從一季一次變成一週一次**。
但兩場重疊 5 天，改數值時進行中的場次不能被影響。

**傾向**：數值表以**賽季為單位快照**。
賽季在封盤期把當時的 `balance` 版本號寫入 `seasons.balance_version`，
整場賽季讀取該版本，**進行中的賽季永遠不受新版本影響**。
新數值只套用到尚未封盤的場次。這也讓 A/B 測試變得可能
（相鄰兩場用不同版本，比較指標）。

| **地圖渲染在低階 Android 卡頓** | 核心體驗不可用 | M1 就以中階 Android 為驗收基準，不留到最後 |
| **Cron 結算延遲累積** | 戰鬥結算不準時，玩家不信任 | 效能預算（1,000 事件 < 10 秒）+ 監控告警 + 必要時改用 QStash 精確排程 |
| **賽季永遠打不完** | 敘事失敗 | 第 12 日期滿積分結算 + 冬季逼迫決戰（`14` §3、`05` §3.1） |
| **冬季把玩家凍住而非逼出來** | 最後 3 天一片死寂，與設計意圖相反 | 兩項冬季驗證條件 + 三段式調整旋鈕（見 B15） |
| **AI 被識破為「假人」而傷害信任** | 社群崩壞 | 誠實原則不可妥協：`◈` 標示、公開人數比與行為腳本、真人排名並列（`15` §2） |
| **AI 主宰地圖／變成免費資源包** | PvE 內容失衡 | 固定腳本曲線 + 六項 AI 驗證（`15` §8）；AI 不可組聯盟、不可觸發勝利 |
| **跨場留存不足** | 短賽季制的根本失敗模式 | D11 開放下一場登記（趁社群關係最熱）；傳承與頭銜；賽季歸檔編年史 |
| **兩場並行時數值熱更新誤傷進行中賽季** | 玩家投資被推翻 | `seasons.balance_version` 快照隔離（見 B16） |
| **首個賽季人數不足（< 100 人）** | 地圖太空曠，遺跡打不下來 | 出生環帶依 N 縮放（`13` §4）；遺跡守衛按比例調降 |
| **單一聯盟壟斷開服** | 賽季 2 週就結束 | 聯盟 50 人上限 + 同行小隊上限 8 人 + v1 不做聯邦 + 遺跡需 9,000 人口長期駐守 |
| **登記人數遠低於預期** | 賽季開不成，社群信心受損 | 登記期第 5 天檢視人數，不足 300 人則延後開賽並公告；同時降低下限至 200 人的小型賽季配置 |
| **三個陣營發展失衡** | 一區壓過另外兩區，賽季提早結束且不精彩 | 陣營硬性名額 ⌈N/3⌉ + 五項出生公平性驗證 + 第 21 天戰力極差 < 25% 的監控 |
| **核心佇列後期停滯感** | 玩家覺得「沒事可做」而流失 | M2 實測（見 B13）；後期的正確去向本就是軍隊與遺跡，需靠 UI 明確引導 |
