# 03 · 資源與經濟

## 1. 五種資源

| 資源 | 代碼 | 主要來源 | 主要用途 | 可否被掠奪 |
| --- | --- | --- | --- | --- |
| 糧食 | `GRAIN` | 農田、主堡基礎產出 | 招兵、**每小時養兵消耗**、前哨營維護 | ✅ |
| 木材 | `TIMBER` | 伐木場 | 所有建築、拓荒隊、攻城單位 | ✅ |
| 石料 | `STONE` | 採石場 | 建築升級、城牆、哨塔 | ✅ |
| 鐵 | `IRON` | 鐵礦坑 | 兵種招募（中高階）、武器科技 | ✅ |
| **遺物** | `RELIC` | 遺跡佔領、廢土營地稀有掉落 | 高階科技、精銳兵種、聯盟科技 | ❌ **永不被掠奪** |

遺物不可掠奪是刻意的：遺物代表「賽季進度」，如果可以被搶，
落後方會被永遠鎖死在落後狀態。遺物只能靠自己打遺跡或清營地取得。

## 2. 產出模型

### 2.1 基礎公式

```
單一設施產出（每小時）
  = 基礎產出(等級)
  × (1 + 地形修正)
  × (1 + 科技加成)
  × (1 + 聯盟遺跡加成)
  × 孤立懲罰（ISOLATED 時 ×0.5）

玩家總產出 = 主堡基礎產出 + Σ 所有領土設施產出 − 養兵消耗 − 前哨營維護
```

基礎產出（每小時）：`10 × level^1.35`（農田／伐木場／採石場），鐵礦坑為 `7 × level^1.35`。

| 等級 | 農田／伐木場／採石場 | 鐵礦坑 |
| --- | --- | --- |
| 1 | 10 | 7 |
| 5 | 43 | 30 |
| 10 | 110 | 77 |
| 15 | 190 | 133 |

主堡基礎產出（不需設施，保底不會餓死）：每種資源 `5 × 主堡等級`/h。

### 2.2 惰性結算（Lazy Accrual）——關鍵技術設計

**不用定時器每秒寫資料庫。** 資源以「快照 + 速率」儲存：

```sql
player_resources(
  player_id,
  grain_amount   NUMERIC,  -- 上次結算時的量
  timber_amount  NUMERIC,
  ...
  grain_rate     NUMERIC,  -- 每小時產出（已扣除消耗，可為負）
  ...
  settled_at     TIMESTAMPTZ  -- 上次結算時間
)
```

讀取時計算：

```
current = clamp(
  amount + rate × (now − settled_at) / 3600,
  0,
  capacity
)
```

只有在**產出速率改變**（蓋建築、升級、兵力變動、領土變動）
或**發生扣款**（招兵、建造、被掠奪）時，才寫入一次資料庫並更新 `settled_at`。

一位玩家平均每天寫入 < 30 次，250,000 格地圖的伺服器成本因此可控。

### 2.3 儲存上限與溢出

| 項目 | 值 |
| --- | --- |
| 基礎上限（每種資源） | 2,000 |
| 倉庫加成 | `+40% × 倉庫等級`（乘算累加） |
| 主堡加成 | `+150 × 主堡等級` |
| 溢出處理 | 超過上限的產出**直接消失**（不入庫，也不通知） |

溢出是這類遊戲讓玩家每天回來的主要機制。
但我們**不做懲罰性溢出**（不扣既有資源），並在介面上顯示「還有 X 小時將溢出」，
讓玩家可以主動規劃，而不是被焦慮驅動。

## 3. 消耗

### 3.1 養兵（糧食）

每個單位每小時消耗糧食，是限制無限爆兵的主要閥門。

| 單位 | 糧耗/h |
| --- | --- |
| 民兵 | 1 |
| 長矛兵 / 劍士 / 弓手 | 1 |
| 掠奪騎兵 | 3 |
| 攻城車 / 投石機 | 4 |
| 精銳單位 | 5 |

**糧食歸零時**：`grain_rate < 0` 且庫存見底 → 每 10 分鐘隨機餓死 3% 的部隊
（優先餓死糧耗最高者）。介面會提前 6 小時紅字警告。

### ★ 冬季：讓餓死成為主要死因

冬季（遊戲月 10–12 / 真實日 D9–D12）產出 ×0.70、糧耗 ×1.30，
**多數玩家的糧食收支會由正轉負**。

這不是懲罰，是賽季的收束機制：

- 你養不起一支不打仗的軍隊 → 龜縮到期滿不再是可行策略
- 遺跡駐軍的糧耗**不受遺跡增益減免** → 控制三座遺跡的聯盟最先挨餓
- 落後者知道對手的軍隊正在流血，冬天是最後的反攻窗口

冬季來臨前 6 小時，遊戲會顯示個人化預測：
「冬季將至：你的糧食收支將由 +340/h 轉為 −180/h，
現有存糧可支撐 14 小時」。**玩家必須看得懂即將發生什麼**，
否則冬天只會變成一場莫名其妙的災難。詳見 `14` §3。

### 3.2 ★ 人口：一種會累積的資源

> **設計變更**：原設計中人口是一個「上限」——升到 Lv20 就立刻有 1,570 人可用，
> 而佔領領土需要消耗民兵，等於**擴張在跟軍隊搶人口**。
>
> 現改為：**佔領領土完全不消耗人口。人口隨主堡緩緩成長，而領地愈多、成長愈快。**

人口不再是瞬間可用的上限，而是**像資源一樣累積**：

```
人口上限   popCap  = 60 × 主堡等級^1.15          ← 天花板，由主堡決定
人口成長率 popRate = (1.5 + 0.3 × 主堡等級) × (1 + 領土數 / 30)  人/小時
                                                 ↑ 領地愈多，長得愈快
可用人口 = min(累積值, popCap)
```

| 主堡 | popCap | 領土 | popRate |
| --- | --- | --- | --- |
| 1 | 60 | 4 | 2.0 / h |
| 5 | 382 | 15 | 4.5 / h |
| 10 | 848 | 30 | 9.0 / h |
| 15 | 1,350 | 45 | 15.0 / h |
| 20 | 1,880 | 60 | 22.5 / h |
| 25 | 2,428 | 75 | 31.5 / h |
| 30 | 2,996 | 90 | 42.0 / h |

### 招兵、陣亡與解散

| 事件 | 人口變化 |
| --- | --- |
| 招募單位 | 扣除（民兵/步/弓 1、騎兵 2、攻城 5、精銳 3） |
| **單位陣亡** | **不返還——人死了就是死了** |
| 主動解散部隊 | 返還 50% |
| 醫療帳傷兵復原 | 不需額外人口（他們沒死） |

**這是整個改動最重要的一點**：人口不是一個可以反覆使用的容器，
而是一條**會被戰爭消耗的河**。打光一支大軍，你的人口也一起消失了，
只能等它慢慢長回來。

### 主堡管上限、領土管補血

這個拆分是刻意的，它讓兩條發展路線都有意義：

| 路線 | 結果 | 弱點 |
| --- | --- | --- |
| **高主堡、低領土** | 軍隊上限大，能組出一支重拳 | 打光了補不回來，**一場敗仗就出局** |
| **低主堡、高領土** | 軍隊上限小，但源源不絕 | 打不出決定性的一擊，只能磨 |
| 均衡 | 兩邊都夠用 | 兩邊都不出色 |

冬季會放大這個差異：產出腰斬時，靠領土補血的玩家受創最重；
而靠主堡撐大軍的玩家會發現自己養不起。

### 為什麼要拿掉「擴張消耗人口」

原設計讓拓荒隊消耗 `5 + ⌊領土/10⌋` 名民兵，且民兵佔人口——
擴張到 120 塊領土累積吃掉約 1,300 人口。

那個張力是真的，但它把**領土**與**軍隊**放在對立面，
結果是「打仗的人不擴張、擴張的人不打仗」，兩種玩法互不相干。

改為「領土加速人口成長」之後，**領土成為戰爭潛力本身**：
你為了打仗而擴張，失去領土不只是失去產出，是失去補兵的速度。
這讓領土戰爭（`02` §2.3 的切細頸）從經濟行為變成軍事行為。

**擴張的煞車改由別處提供**（見 `02` §2.2、`11` §4）：
資源成本 `×(1 + 領土/15)`、立旗時間 `×(1 + 領土/20)`、
領土容量硬上限 `4 × 主堡等級`，以及最重要的——**守不守得住**。

## 4. 掠奪與保護

### 4.1 地窖 Vault

每位玩家有一個隱藏地窖，**其中的資源永遠不會被掠奪**：

```
地窖保護量（每種資源）= 300 + 80 × 倉庫等級 + 30 × 主堡等級
```

沒蓋倉庫的玩家（Lv1 主堡）保護 330；蓋滿倉庫的玩家可保護 3,000+。
這給了「倉庫」這個核心建築格明確的價值。

### 4.2 掠奪上限

攻方能搶走的量 = `min(部隊總載重, Σ 每種資源的未保護量)`。

各資源按未保護量的比例分攤載重（不會只搶一種）。

| 單位 | 載重 |
| --- | --- |
| 民兵 | 25 |
| 長矛兵 | 40 |
| 劍士 | 50 |
| 弓手 | 35 |
| **掠奪騎兵** | **140** |
| 攻城車 / 投石機 | 0 |

掠奪騎兵載重是劍士的近 3 倍，這讓「劫掠流」成為一個真正可行的資源策略，
而不只是戰鬥策略。

### 4.3 重複劫掠遞減（反霸凌）

```
同一攻方對同一守方，6 小時內第 n 次成功掠奪：
  實際掠奪量 × 0.6^(n-1)
  第 1 次 100%、第 2 次 60%、第 3 次 36%、第 4 次 21.6%…
```

同時，守方連續被同一人打第 3 次後，會收到系統提示與「求援」按鈕，
一鍵發送求援訊息到聯盟頻道（附座標與敵方兵力偵查值）。

## 5. 交易：**只能與同盟成員進行**

> **設計變更**：原設計開放全服自由交易（5% 稅，同盟免稅）。
> 現改為 **交易對象必須是同一聯盟的成員**。

| 規則 | 說明 |
| --- | --- |
| 交易對象 | **僅限同一聯盟成員**。無聯盟者完全無法交易 |
| 前置建築 | **掛單方**需有 **集市 Market**（每位玩家上限 1 座，佔 1 格領土） |
| 承接方 | 不需要集市 |
| 稅 | **無**（聯盟內部沒有中間商） |
| 遺物 | 不可交易 |
| 運送 | 商隊速度 60 格/h，**v1 不可攔截** |
| 防小號互餵 | 資源轉移日上限 `500 × 主堡等級` |

### 這讓聯盟從「有比較好」變成「非有不可」

資源不可跨類轉換（見 §7.2），所以「石頭滿了但木頭見底」是必然會發生的困境。
在原設計裡，你可以去集市跟任何人換。現在你只有兩條路：

```
加入聯盟，跟盟友換   ←→   去搶
```

**沒有第三條路。** 這把經濟壓力直接轉化為社交或軍事行為，
而不是轉化為一次無關痛癢的市場操作。

### 集市成為聯盟內的角色分工

每位玩家只能蓋 1 座集市，而它佔用一格寶貴的領土
（那格本來可以是農田或哨塔）。
掛單需要集市、承接不需要 → 聯盟裡自然會出現**一兩位「商人」**，
由他們承擔這個成本，替全聯盟做資源調度。

這是 v1 少數幾個不靠系統強制、而是靠成本結構自然長出來的角色。

## 6. 經濟曲線目標

目標為**中位數真人玩家**在 12 天賽季中的軌跡
（對照 AI 腳本曲線見 `15-ai-players.md` §4）：

| 遊戲月（真實日） | 季 | 主堡 | 領土 | 兵力（人口） |
| --- | --- | --- | --- | --- |
| 3（D2–D3） | 春末 | Lv10–12 | 18–25 | 200–350 |
| 6（D5–D6） | 夏末 | Lv17–19 | 42–50 | 700–1,100 |
| 9（D8–D9） | 秋末 | Lv22–24 | 62–72 | 1,500–2,200 |
| 12（D11–D12） | 冬末 | Lv25–27 | 70–85 | 1,800–2,600 |

**主堡 Lv30 在 12 天內幾乎不可能達成**，這是刻意的：
賽季結束時大多數人停在 Lv25–27，天花板始終在望而不可及，
資源的正確去向永遠是軍隊與遺跡，而不是把建築點滿。

第 12 月的兵力成長趨緩甚至倒退——那是冬季（見 `14` §3）的效果。

**設計檢查點**：任何時候，一位「每天上線 3 次、每次 5 分鐘」的休閒玩家，
戰力不應低於「每天上線 10 次」玩家的 50%。
行軍計時制天然壓縮了勤勞度差距——這是選擇這個時間模型的主要理由之一。

## 7. ★ 資源稀缺與強制取捨

這是整份企劃的核心張力。**遊戲的樂趣不在於累積資源，在於決定資源要去哪裡。**

### 7.1 五個競爭中的去向

所有資源最終流向這五處，它們**互相排擠**：

| 去向 | 消耗 | 佔用 | 換到 |
| --- | --- | --- | --- |
| **主堡升級** | 木・石・鐵 | **核心佇列** | 上限（領土容量、**人口天花板**、建築等級上限） |
| **核心建築 B/C/D** | 木・石・鐵 | **核心佇列** | 能力（練兵速度、防禦、儲存、攻城） |
| **領土設施** | 木・石 | 領土佇列 | 產出（每小時的資源流） |
| **招募軍隊** | 糧・木・鐵 + **人口** | 兵營佇列 + **持續糧耗** | 戰力（現在就能用） |
| **拓荒擴張** | 糧・木（**不再消耗人口**） | 領土佇列 | 產出潛力 + **人口成長率** + **區域軍隊容量** |

前兩者**共用同一條永不增加的核心佇列**（見 `02` §1.1）——這是最尖銳的一刀。

### 7.2 四道無法迴避的閘門

| 閘門 | 機制 | 造成的取捨 |
| --- | --- | --- |
| **時間** | 核心佇列永遠只有 1 條 | 升主堡 = 不升兵營 |
| **資源** | 成本指數 `1.28^L`，資源不可跨類轉換 | 每一次升級都排擠掉別的升級 |
| **人口** | 上限由主堡決定、成長率由領土決定，**陣亡不返還** | 大軍上限 vs 續戰補血 |
| **補給** | 區域軍隊容量由當地基礎建設決定（見 `16`） | 想在遠方打仗，得先在遠方建設 |

**資源不可跨類轉換**是刻意的：「我石頭滿了但木頭不夠」是一個真實困境，
而現在**交易只能跟同盟成員進行**（見 §5），
所以唯二的解法是**加入聯盟**或**去搶**。
這讓經濟壓力直接轉化為社交與軍事行為，沒有第三條路。

### 7.3 第 3 天的十字路口（實例）

假設一位中原帶玩家在 T+72h 手上有 **木 3,200 / 石 2,400 / 鐵 900 / 糧 2,100**，
主堡 Lv6，核心佇列空著。三條路，只能選一條：

| 選擇 | 花費 | 佔用核心佇列 | 第 7 天的你 |
| --- | --- | --- | --- |
| **A · 衝主堡 Lv9** | 木 2,900 / 石 2,400 / 鐵 1,100 | **6 小時** | 人口天花板 740、領土容量 36、建築上限 Lv9。**但幾乎沒有兵**，只能靠固有防禦（1,080）與求鄰居 |
| **B · 兵營 Lv6 + 40 劍士** | 木 1,700 / 石 1,400 / 鐵 4,200 | 3 小時 | 主堡卡 Lv6（容量 24、人口 400），**但你是這一帶最能打的人**，可以靠劫掠養自己 |
| **C · 鋪 8 座領土設施** | 木 3,100 / 石 800 | 0（走領土佇列） | 產出翻倍，主堡與軍隊都沒動。**第 7 天最有錢，第 8 天最容易被搶** |

三條路在第 7 天會長成**三種完全不同的玩家**，
而他們是鄰居——A 需要 B 的保護，B 需要 C 的資源，C 需要 A 的空間。
**取捨產生分工，分工產生聯盟。**

### 7.4 設計檢查：取捨是否真的存在

如果以下任何一項在實測中不成立，代表取捨被稀釋，必須調回：

- [ ] 第 7 天，全服前 20% 玩家的 build（B/C/D 三格組合）**至少出現 5 種不同組合**
- [ ] 第 14 天，主堡等級與總兵力的相關係數 **< 0.6**（若接近 1，代表根本沒有取捨，大家都在做同一件事）
- [ ] 核心佇列的平均閒置率 **< 10%**（若常常空著，代表資源不夠稀缺，或成本太低）
- [ ] 集市的日成交量 **> 全服日產出的 8%**（代表資源不可轉換確實造成了真實的短缺與交易需求）
