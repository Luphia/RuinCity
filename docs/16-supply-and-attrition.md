# 16 · 補給、區域容量與戰爭節奏

> **設計變更紀錄**：原設計用「新手保護期」（註冊後 12–24 小時不可被攻擊）
> 保護弱勢玩家。**已完全廢除。**
>
> 保護期是個補丁：它是二元的、武斷的、且會製造懸崖——
> 到期的那一秒你突然變成獵物。它在第 1 天保護你，在第 8 天什麼也不做。
>
> 取而代之的是四個**有機**的限制：**耗糧、補給線、城池防禦、區域軍隊容量**。
> 它們不是規則例外，而是世界運作的方式；
> 它們在整場賽季都有效，而且強度自然隨局勢變化。

## 1. 核心原則

> **你能在一個地方投入多少兵力，取決於你在那裡有多少基礎建設。**

這一句話同時給出了四件事：

| 它自然產生 | 因為 |
| --- | --- |
| **新手保護** | 攻方在新手的區域沒有任何建設 → 只能投入基礎容量的兵力 |
| **補給線** | 領土與前哨營就是補給網；想在遠方作戰，得先在遠方蓋東西 |
| **防守優勢** | 守方在自家區域有最多建設 → 天然的主場容量優勢 |
| **戰爭節奏** | 建設需要時間 → 春天打不起來；季節係數讓秋天最能遠征、冬天必須收縮 |

## 2. 區域 Region

地圖切成 **10 × 10 = 100 個區域**，每個 **50 × 50 格**。
區域在地圖上可見（L3 戰略視圖顯示格線與編號），並有名字：
「第 47 區 · 鏽谷」——戰報與聯盟日誌都會用它。

### 2.1 區域軍隊容納上限

**以聯盟為單位計算**（無聯盟者以個人計）：

```
聯盟 A 在區域 R 的容納上限
  = 2,000                                    ← 基礎（無需任何建設）
  + A 在 R 內的領土格數        × 150
  + A 在 R 內的前哨營等級總和  × 800
  + A 在 R 內的核心據點主堡等級總和 × 100
  ─────────────────────────────────────
  × 季節係數（春 0.8 / 夏 1.0 / 秋 1.3 / 冬 0.6）
```

計入的兵力：該區域內所有**停駐**的部隊（駐軍、增援、圍攻中、遺跡駐防）。
**行軍中路過的部隊不計入**——移動中的軍隊不需要就地補給。

### 2.2 超限懲罰

```
若聯盟在某區域的停駐兵力 > 容納上限：
  每小時：超出部分損兵 5%
          該區域內我方全體部隊糧耗 ×1.5
```

不是硬性禁止，是持續失血。你**可以**硬塞，但你在燒兵。
這讓「孤注一擲的深入突襲」仍然可行（打完就走），
但「沒有後勤的長期圍攻」會自己瓦解。

### 2.3 實際數字感

| 情境 | 容納上限（夏季） | 冬季 |
| --- | --- | --- |
| 攻方在敵區毫無建設 | **2,000** | 1,200 |
| 攻方已建 1 座 Lv3 前哨營 | 4,400 | 2,640 |
| 攻方已建 2 座 Lv5 前哨營 + 佔 10 格 | 11,500 | 6,900 |
| 守方在自家區域（15 領土 + 主堡 Lv20） | 6,250 | 3,750 |
| 守方 + 3 名同盟鄰居（各 15 領土 + Lv18） | 14,150 | 8,490 |

**讀法**：

- 沒有前置作業，你在敵人家門口最多只能維持 2,000 人。
  對上有 6,000 容量的守方聯盟，你打不下來。
- 想真的攻下一個區域，你必須**先在那裡蓋前哨營、先佔幾格地**——
  而那需要時間、資源，以及先打贏幾場小仗。**戰爭因此是推進式的。**
- 冬季 ×0.6 讓所有前線部署縮水四成。
  秋天沒建好的，冬天就別想了。

### 2.4 為什麼是 50×50

- 一個陣營的版圖（半徑約 105 格）橫跨 4–9 個區域 → 內部有多個戰線
- 一格領土 = 容量 +150，一個區域塞滿 2,500 格但玩家最多只有 120 格領土 →
  單一玩家最多貢獻 18,000 容量，需要整個聯盟才撐得起大規模會戰
- 邊界可被鑽（把軍隊停在區外一格）——但懲罰是漸進的失血而非二元禁止，
  停在區外只是把問題推給另一個區域。**不值得為此加複雜度。**

## 3. 耗糧：主要的用兵閥門

糧食是限制軍隊規模的第一道閥門，
而**區域超限會讓糧耗暴增 50%**，兩者相乘。

| 單位 | 糧耗/h |
| --- | --- |
| 民兵 / 長矛 / 劍士 / 弓手 | 1 |
| 掠奪騎兵 / 重騎兵 | 3 |
| 攻城車 / 投石機 | 4 |
| 精銳 | 5 |

**冬季 ×1.3**（見 `14` §3）。**區域超限 ×1.5**。兩者疊乘可達 **×1.95**。

一支 5,000 人的遠征軍，在冬季、在無建設的敵區：
糧耗約 `5,000 × 1 × 1.3 × 1.5 = 9,750/h`，
外加每小時損兵 5%。**它會在一天內自己消失。**

## 4. 城池防禦：讓進攻昂貴

### 4.1 據點固有防禦

即使一堵牆都沒蓋，據點本身就有防禦力：

```
核心據點固有防禦 = 主堡等級 × 120
領土格固有防禦   = 設施等級 × 30（哨塔另加 200 × 等級）
```

| 主堡 | 固有防禦 |
| --- | --- |
| Lv1 | 120 |
| Lv5 | 600 |
| Lv10 | 1,200 |
| Lv20 | 2,400 |

這是**取代新手保護期的核心機制之一**：
一位 Lv5 玩家帶著 100 名民兵與長矛（約 1,500 防禦），
加上固有防禦 600，總計 2,100——
足以擊退一個帶 50 名劍士（2,400 攻擊 × 士氣 0.6 ≈ 1,440）的早期侵略者。

固有防禦在後期相對微不足道（Lv20 的 2,400 對上萬人大軍是零頭），
**保護的強度自然隨玩家成長而淡出**——這正是保護期做不到的事。

### 4.2 沒有攻城器械就別想拆牆

```
若守方城牆等級 > 0 且攻方部隊不含任何攻城單位：
  攻方戰力 × (1 − 0.05 × 城牆等級)，最多 −50%
```

早期人人城牆低，突襲容易；
後期要打下有城牆的據點必須帶攻城車——
而攻城車速度只有 24 格/h、糧耗 4、佔人口 5，
**它們是後勤負擔的化身**。這讓「認真的進攻」在時間與補給上都昂貴。

### 4.3 醫療帳（不變）

守方在自己據點防守陣亡的部隊，
`25% + 2% × 醫療帳等級`（上限 60%）轉為傷兵可復原。
攻方陣亡不回收。守家在成本上始終佔優。

## 5. 士氣：讓欺負弱者無利可圖

```
士氣係數 = min(1.0, (守方人口 / 攻方人口)^0.35)
```

指數由 0.25 **提高到 0.35**，並且——這是關鍵改動——

> **士氣同時套用於攻方戰力與攻方的掠奪量。**

| 攻/守人口比 | 士氣 | 攻方戰力 | 攻方掠奪 |
| --- | --- | --- | --- |
| 1:1 | 1.00 | 100% | 100% |
| 2:1 | 0.78 | 78% | 78% |
| 5:1 | 0.56 | 56% | 56% |
| 10:1 | 0.45 | 45% | 45% |
| 20:1 | 0.35 | 35% | 35% |

再疊上**地窖保護**（春季 ×2，見 §7）與**重複劫掠遞減**（`0.6^(n-1)`，6 小時內），
打一個新手能拿到的東西趨近於零。

**額外規則**：攻擊人口低於自己 1/5 的玩家，**不計入任何賽季積分**。

士氣不適用於遺跡爭奪戰（終局內容不該被反霸凌機制干擾）。

## 6. 單一位置的駐軍上限

區域容量管的是「一片地區能養多少兵」；
駐軍上限管的是「一個點能塞多少兵」，防止單點堆疊無敵要塞：

| 位置 | 駐軍上限（人口） |
| --- | --- |
| 核心據點 | `1,000 + 400 × 主堡等級` |
| 領土格 | `200 + 300 × 設施等級` |
| 前哨營 | `1,500 + 1,200 × 前哨營等級` |
| 遺跡 | 3,000（不變） |

- 超過上限的增援／駐防指令直接被拒絕（UI 事前提示，不會浪費行軍）
- **出擊部隊規模 ≤ 出發地的當前駐軍量**，因此駐軍上限也限制了單次進攻的規模
- 想投入 15,000 人的總攻，你需要**多個前哨營同時出兵**——
  而那需要協調抵達時間（v1 沒有集結功能，玩家得自己算，見 `06` §2）

## 7. 廢除新手保護期後，第 1 天的玩家會發生什麼

**他可以被攻擊。** 這是刻意的——沒有魔法護盾。
但讓我們算一下攻擊他的收益：

一位 Lv1 新手，10 民兵，庫存約 600 各項資源。
一位第 2 天的侵略者帶 200 劍士來打他。

| 項目 | 計算 |
| --- | --- |
| 守方防禦 | 10 民兵 × 12 = 120，+ 固有防禦 120 = **240** |
| 攻方戰力 | 200 × 48 = 9,600，士氣 `(10/200)^0.35 = 0.36` → **3,456** |
| 結果 | 攻方壓倒性勝利，損失趨近 0 |
| **可掠奪資源** | 庫存 600 − 地窖保護（330 × 春季 2 倍 = **660**）= **0** |
| **實際收穫** | **零** |
| 攻方成本 | 200 劍士離家 1 小時、糧耗 200、區域超限風險 |
| 賽季積分 | **0**（人口比超過 5:1） |

新手損失：10 名民兵（= 約 3 小時的人口成長）。**是一堂課，不是災難。**
侵略者收穫：什麼都沒有，還浪費了一小時的兵力調度。

**沒有任何規則禁止這次攻擊——它只是不值得。**
這比保護期好的地方在於：同樣的邏輯在第 8 天保護一個落後的玩家，
而保護期早就過期了。

### 春季地窖加厚

```
地窖保護量 = (300 + 80 × 倉庫等級 + 30 × 主堡等級) × 春季 2 倍
```

春季（D0–D3）地窖保護加倍，是唯一保留的「時間性」保護——
但它保護的是**資源**而非玩家本身，且對所有人一視同仁（老手也享有）。
它不阻止戰鬥，只是讓早期的劫掠無利可圖。

## 8. 四季如何驅動戰爭節奏

這是整份設計要達成的目標：**用兵集中在夏秋，冬季是生存決戰。**

| 季 | 真實日 | 區域容量 | 產出 | 糧耗 | 行軍 | 戰爭形態 |
| --- | --- | --- | --- | --- | --- | --- |
| **春 荒芽** | D0–D3 | **×0.8** | ×1.10 | ×1.0 | ×1.0 | 幾乎沒有。人口剛起步、無建設、地窖加倍 |
| **夏 焦土** | D3–D6 | ×1.0 | ×1.00 | ×1.0 | ×1.0 | 領土衝突。遺跡解封，開荒競速 |
| **秋 豐鏽** | D6–D9 | **×1.3** | ×1.20 | ×1.0 | ×1.0 | **遠征的唯一窗口**。大會戰 |
| **冬 長夜** | D9–D12 | **×0.6** | ×0.70 | ×1.30 | ×1.25 | **生存決戰**。遠征軍必須撤回或餓死 |

### 春天為什麼打不起來（不需要保護期）

- 人口成長率在 Lv1–5 只有 2–5/h → 你根本沒兵
- 區域容量 ×0.8，且沒人有建設 → 上限只有 1,600
- 地窖保護加倍 → 搶不到東西
- 遺跡封印中 → 沒有值得爭的目標

**戰爭在春天不發生，不是因為被禁止，是因為不划算。**

### 秋天為什麼是遠征窗口

區域容量 ×1.3 是唯一一次「就地補給」變容易的時候。
一個在敵區建了 2 座 Lv5 前哨營的聯盟，秋季容量 11,500——
足以支撐一場真正的圍城。過了秋天，同樣的建設只剩 6,900。

**秋季的行動決定冬季的存亡。** 沒在秋天推進到位的聯盟，冬天只能守。

### 冬天為什麼是生存決戰

```
冬季，一支在敵區無建設的 3,000 人遠征軍：
  容量上限 = 2,000 × 0.6 = 1,200
  超出 1,800 人 → 每小時損兵 90 人
  糧耗 = 3,000 × 1.3 × 1.5 = 5,850/h（而你的產出只剩 70%）
  → 兩天內化為烏有
```

所有沒有後勤支撐的部隊都會撤回本土。
戰爭因此收縮到每個人的家門口——
搶最後的資源、守住最後的領土、賭對手先餓死。

**冬季的問題不是「我能打下哪裡」，是「我撐不撐得到第 12 天」。**

### 遺跡持有者在冬季的處境

同時控制三座遺跡需要 12,000–18,000 人口的前線駐軍（見 `05` §2.3）。
冬季區域容量 ×0.6 意味著：**秋天沒在遺跡周邊建好基礎設施的聯盟，
冬天根本守不住。**

一個在秋季於遺跡所在區域建了 30 格領土 + 3 座 Lv3 前哨營的聯盟：

```
夏季容量 = 2,000 + 30×150 + 9×800 = 13,700
冬季容量 = 13,700 × 0.6 = 8,220     ← 仍足以支撐 3,000 遺跡駐軍 + 5,000 野戰軍
```

而挑戰者若在該區毫無建設，冬季只有 1,200 容量——打不動。

**結論：遺跡的歸屬在秋天就決定了，冬天只是驗收。**
這給了秋季大會戰真正的份量，也讓「早點拿到遺跡」不等於贏——
你還得在周圍蓋出能撐過冬天的補給網。

## 10. 平衡驗證

- [ ] **無任何一場戰鬥發生在遊戲月 1–2（D0–D2）** 的玩家比例 > 90%
      （春天不該有戰爭，但也不該完全禁止）
- [ ] 戰鬥次數分布：夏 + 秋（D3–D9）佔全季 **≥ 65%**
- [ ] 冬季（D9–D12）戰鬥次數 ≥ 秋季同期的 **80%**，
      但**遠征距離中位數下降 ≥ 50%**（驗證「戰爭收縮到本土」）
- [ ] 因區域超限而損失的兵力，佔全季總損兵 **5–15%**
      （太低 = 機制沒作用；太高 = 玩家看不懂，體驗糟）
- [ ] 第 1 天被攻擊的新手，其資源損失中位數 **= 0**
- [ ] 攻擊人口比 > 5:1 的戰鬥次數，佔全季 **< 8%**
      （驗證欺負弱者確實無利可圖）
- [ ] 前哨營總數在秋季達到峰值，且冬季**淨減少**（驗證前線收縮）
