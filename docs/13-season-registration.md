# 13 · 賽季登記與同時開賽

> **設計變更紀錄**：原始設計為「外環螺旋入場」——玩家陸續註冊、由外向內填入環帶，
> 用地理位置補償晚加入者的進度落後。
> 現改為 **事先登記制 + 全員同時進入**。
>
> 外環螺旋本質上是個補丁：它承認了「晚進來的人吃虧」並試圖補償。
> 同時開賽直接消滅這個問題，並帶來三個原本拿不到的好處：
> **(1)** 開賽前 N 已知 → 出生點分配從貪婪插入變成可驗證的批次最佳化；
> **(2)** 賽季成為有明確起跑槍的賽事，社群期待與敘事完整；
> **(3)** 登記表單本身成為第一個做決策的場景。

## 1. 賽季生命週期

```
┌─ 登記期 ─────────── 7 天 ──────────┐
│  開放登記                           │
│  玩家選擇：陣營 / 出生帶 / 同行小隊  │
│  即時顯示各名額剩餘（製造決策壓力）   │
└─────────────────────────────────────┘
              ↓
┌─ 封盤期 ─────────── 24 小時 ────────┐
│  停止登記                           │
│  執行地圖生成 + 出生點批次分配        │
│  公平性驗證（未通過則換 seed 重跑）   │
│  公布地圖預覽與自己的出生座標         │
│  預組小隊確認彼此位置                │
└─────────────────────────────────────┘
              ↓
         ▶ T = 0 開戰 ◀
       所有人同時進入，資源同時開始累積
              ↓
┌─ 賽季 ───────── 5–8 週 ────────────┐
│  第 1 週  發育與地緣認識              │
│  第 2–3 週 領土衝突、聯盟成形          │
│  第 3–4 週 遺跡守衛被清空             │
│  第 4–6 週 遺跡爭奪                  │
│  終局     三遺跡同控 24 小時 → 結束    │
└─────────────────────────────────────┘
              ↓
┌─ 終戰期 ─────────── 24 小時 ────────┐
│  地圖凍結、結算、歸檔                │
└─────────────────────────────────────┘
              ↓
┌─ 賽間期 ─────────── 7 天 ──────────┐
│  傳承點兌換、下賽季登記開放           │
└─────────────────────────────────────┘
```

**封盤期公布地圖預覽**是刻意的：玩家在開戰前 24 小時就知道自己生在哪、
鄰居是誰、離哪座遺跡最近。這 24 小時會產生大量社群活動
（找鄰居結盟、在論壇上約定互不侵犯、規劃第一週路線）——
賽季的社交網路在第一顆資源產出之前就已經開始編織。

## 2. 登記時的三個選擇

登記表單不是填資料，是做戰略決策。所有選擇**送出後不可更改**。

### 2.1 選擇一：陣營（三選一，硬性名額）

地圖依三座遺跡做 Voronoi 分割成三個區域（山脈作為天然邊界，
會讓分割線不規則——這是好的，地緣從一開始就不對稱）。

| 陣營 | 遺跡 | 遺跡增益 | 預期區域性格 |
| --- | --- | --- | --- |
| **灰燼氏族** | I 灰燼尖塔 | 行軍速度 +20% | 機動掠奪流聚集，衝突頻繁但規模小 |
| **穹窖商會** | II 沉沒穹窖 | 資源 +25%、地窖 +50% | 發育流聚集，前期最和平、中期最富 |
| **鐵搖籃盟** | III 鐵之搖籃 | 攻防 +12% | 戰鬥流聚集，開局就是血肉磨坊 |

#### 動態名額（避免雞生蛋問題）

「每陣營 = 總人數 / 3」在登記進行中無法計算——總人數還在變。
因此名額採**隨登記總數動態成長**：

```
單一陣營容量 = max(20, ⌈目前總登記數 × 1.08 / 3⌉)
```

| 目前總登記 | 每陣營容量 | 單一陣營佔比上限 |
| --- | --- | --- |
| 60 | 22 | 36% |
| 300 | 108 | 36% |
| 900 | 324 | 36% |
| 1,500 | 540 | 36% |

**性質**：

- 容量隨總數成長 → 早鳥無法全部擠進同一個陣營，
  第 N 個人要進熱門陣營，得先有另外兩個人選別的陣營把總數推上去
- 係數 **1.08** 提供緩衝，確保 `3 × 容量 > 總數`，
  **不會出現三個陣營同時額滿而無人能登記的死鎖**
- 數學上鎖死最大失衡：任一陣營 ≤ 36%，任一陣營 ≥ 28%（最壞情況 36/36/28）
- 名額剩餘數在登記頁即時顯示，並顯示「再有 N 人登記就會開放更多名額」

#### 封盤時的最終再平衡

若封盤時三陣營人數極差仍 > 20%（理論上不會，但保留機制）：
系統向**人數最多陣營**的玩家發出自願轉調邀請，
接受者獲得「調防補給」（起始資源 +25%），額滿即止。
**絕不強制轉調**——玩家的選擇必須被尊重，否則整個「選擇即玩法」的前提就垮了。

#### 出生帶名額

同樣採動態計算，在陣營內按比例分配：

```
出生帶容量 = max(6, ⌈該陣營目前人數 × 比例 × 1.15⌉)
比例：前線 20% / 中原 50% / 邊陲 30%
```

**為什麼這個設計好**：三座遺跡的增益不同 → 選陣營等於宣告你的玩法傾向 →
同區域的玩家玩法相似 → **區域自然演化出不同的性格**。
鐵搖籃區會在第一週就打成一片，穹窖區會先安靜地種田到第三週。
然後這三種截然不同的勢力在第四週撞在一起。

這是免費得到的敘事，只因為讓玩家在登記時做了一個選擇。

**風險與對策**：陣營並不保證你能拿到該區的遺跡——你只是生在它旁邊，
而且你的所有鄰居都想要它。硬性名額上限確保三區人數相等，
不會出現一區壓死其他兩區。

### 2.2 選擇二：出生帶（三選一，區域內名額）

在自己的陣營區域內，選擇離遺跡的距離：

| 出生帶 | 離遺跡距離 | 區域名額 | 得到 | 付出 |
| --- | --- | --- | --- | --- |
| **前線 Vanguard** | 25–60 格 | 20% | 周邊廢土營地等級 +3（遺物來源近）；起始 1 塊額外領土容量 | 新手保護僅 **48 小時**；戰火最早波及 |
| **中原 Heartland** | 60–120 格 | 50% | — | — |
| **邊陲 Frontier** | 120–200 格 | 30% | 起始資源 **+40%**；新手保護 **96 小時** | 離遺跡遠，遠征需靠前哨營接力 |

交換的是**安全 vs 接近終局**，不是單純的數值強弱。
前線玩家更早拿到遺物、更早練出精銳，但也更早死。

### 2.3 選擇三：同行小隊（選填）

登記時可填入一組「同行代碼」，**最多 8 人**共用同一組代碼。

```
系統保證：同代碼的玩家分配在同一個群集內，彼此距離 8–15 格
限制：
  - 同行小隊成員必須選擇相同陣營與相同出生帶（否則代碼失效）
  - 上限 8 人（不是聯盟上限 50 人）
```

**為什麼是 8 不是 50**：讓朋友能一起開始是必要的（否則社群留不住），
但如果整個 50 人聯盟能抱團開局，那一區會被單一勢力直接壓死。
8 人是「一群朋友」的規模，不是「一支軍隊」的規模。
聯盟仍然要在賽季開始後靠外交組成。

## 3. 出生點批次分配演算法

因為所有人同時進入，任何不公平都會在第一天被玩家攤在論壇上比較。
分配必須是**可驗證公平**的，不能靠隨機祈禱。

```
輸入：N 位登記玩家（陣營、出生帶、同行代碼）、賽季 seed

1. 地圖生成（seed）→ 地形 + 三座遺跡位置（約束見 01-world-map.md §4）

2. Voronoi 分割：以三座遺跡中心為種子，用「行軍成本距離」而非直線距離
   （山脈成本極高）→ 三個區域。山脈自然成為區域邊界。

3. 環帶劃分：每區域內依離遺跡的距離劃出 前線 / 中原 / 邊陲 三環

4. 候選點生成：每個環帶內用 Poisson-disk sampling
     最小間距 r = sqrt(環帶可用面積 / 該環帶人數) × 0.8
     排除：MOUNTAIN、遺跡禁建圈（半徑 12）、地圖邊界 10 格內、
           2×2 範圍內含 MOUNTAIN 者

5. 同行小隊優先：先把小隊分配到「群集」（一組候選點，彼此 8–15 格），
   再分配散客到剩餘點位

6. ★ 公平性驗證（任一項不通過 → 換 seed，回到步驟 1）：
     (a) 每位玩家 15 格內的可建設格數（非山脈、非禁建圈），
         全服標準差 < 8%
     (b) 同一環帶內，玩家到最近遺跡的距離極差 < 20 格
     (c) 每位玩家 30 格內的鄰居數，全服極差 ≤ 2
     (d) 每位玩家 20 格內的高價值地形（LODE + FOREST）格數，
         全服標準差 < 12%
     (e) 三個區域的可用總面積差異 < 5%

7. 輸出出生點表 → 封盤期公布 → T=0 一次性寫入
```

**步驟 6 是整個系統的重點**。它把「這張圖公不公平」從主觀爭論變成
一組可以公開的數字。我們應該在封盤期**直接公布這五項驗證的實際數值**，
讓玩家自己確認。透明度是這類遊戲最便宜也最有效的信任來源。

**換 seed 重跑的成本**：地圖生成 + 分配 + 驗證在一般伺服器上約 20–60 秒，
封盤期有 24 小時，跑上百次都沒問題。

## 4. 登記人數與地圖密度

500×500 = 250,000 格。密度決定衝突發生的時間點：

| 密度 | 每人格數 | 對應人數 | 體驗 |
| --- | --- | --- | --- |
| 寬鬆 | 250 | 1,000 | 第 3 週才碰到鄰居，前期太孤單 |
| **建議** | **165** | **1,500** | 第 1 週認識鄰居，第 2 週開始搶地 |
| 標準 | 120 | 2,080 | 節奏快，第 1 週就有衝突 |
| 擁擠 | 83 | 3,000（硬上限） | 開局就是絞肉，適合老玩家專場 |

**營運規則**：
- 單一賽季建議登記上限 **1,500 人**
- 超過上限 → **開第二座同時起跑的賽季伺服器**（`S5-A` / `S5-B`），
  而不是把人硬塞進同一張圖
- 登記不足 800 人 → 縮小出生環帶半徑（`R = sqrt(N/3 × 165 / π)`），
  外圍地圖仍存在但成為無人的荒野與 PvE 區

**登記不足時不縮小地圖尺寸**，只縮小出生環帶。
這保留了「地圖很大、外面還有未知」的感覺，
而外圍荒野正好是廢土營地與前哨營補給線的舞台。

## 5. 中途加入的玩家

同時開賽的代價：賽季開始後才想玩的人怎麼辦？

**決策：賽季開始後 14 天內仍可加入，之後關閉。**

| 加入時間 | 待遇 |
| --- | --- |
| T+0 ~ T+3 天 | 正常出生點（從各環帶預留的 5% 緩衝名額分配） |
| T+3 ~ T+14 天 | 出生於**邊陲帶**；獲得「後進者補給」：起始資源按全服中位數的 60% 折算 |
| T+14 天之後 | **不可加入**，導向下一賽季登記頁 + 觀戰模式 |

- 「後進者補給」只補資源，**不補主堡等級、不補兵力、不補領土**。
  他追得上經濟，但追不上版圖——這是合理的，他確實晚到了。
- 觀戰模式讓等待下賽季的玩家能看地圖、看排行榜、加入聯盟的 Discord，
  維持社群黏著。這是把「不能玩」轉成「準備下一場」的關鍵。

T+14 的硬性關閉是必要的：如果一直開放，
第 5 週進來的新人只會被當成資源包收割，體驗極差且傷害口碑。

  傾向：登記需通過 email 驗證，且 T+24 小時未登入者的出生點自動回收為中立空地。

  傾向：不加開。稀缺是設計的一部分，但應在登記開放前 48 小時公告確切時間。
