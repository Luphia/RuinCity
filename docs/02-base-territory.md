# 02 · 據點與領土

> **設計變更紀錄**：原始構想為 4×4 據點。經討論後改為
> **固定 2×2 核心據點 + 可向外佔領相鄰領土**。
> 核心格從 16 → 4，稀缺性大幅提升，玩家必須在建築之間做真正的取捨；
> 而「變大」的成就感由領土系統承擔，且領土是可以被打下來的，戰爭因此有意義。

## 1. 核心據點（Core / 2×2）

| 屬性 | 說明 |
| --- | --- |
| 佔地 | 固定 2×2 = 4 格，賽季內不可移動 |
| 不可摧毀 | 核心據點永遠屬於玩家，被攻破只會掉等級與被掠奪，不會消失 |
| 格位編號 | `A` 左上、`B` 右上、`C` 左下、`D` 右下 |
| 格位 A | **強制為主堡（Citadel）**，不可拆除 |
| 格位 B/C/D | 玩家自由選擇建築，可拆除重建 |

### 1.1 主堡 Citadel（固定於 A）

主堡是整個帳號的等級核心，決定：

| 主堡等級影響 | 公式 |
| --- | --- |
| 領土容量 | `4 × 主堡等級` 格（不含核心 4 格） |
| 可解鎖建築等級上限 | 其他建築等級 ≤ 主堡等級 |
| **人口天花板** | `60 × 主堡等級^1.15`（成長率則由領土數決定，見 `03` §3.2） |
| **據點固有防禦** | `主堡等級 × 120`（不需城牆，見 `16` §4.1） |
| **據點駐軍上限** | `1,000 + 400 × 主堡等級`（見 `16` §6） |
| **領土設施佇列** | `1 + ⌊主堡等級 / 10⌋`（1–4 條） |
| **核心建造佇列** | **永遠 1 條**（見下） |
| 最高等級 | Lv30 |

### ★ 核心建造佇列永遠只有一條

主堡與 B/C/D 三座核心建築 **共用唯一一條建造佇列**，
且這條佇列**不會因為任何等級、科技或付費而增加**。

這是整個遊戲最尖銳的取捨點。它的意思是：

> **每一分鐘你在升級主堡，就是一分鐘你沒有在升級兵營。**

主堡從 Lv1 到 Lv30 的純建造時間約 7 天，佔滿這條佇列。
若你把時間分給兵營與城牆，主堡就上不去；主堡上不去，
領土容量、人口上限、以及其他建築的等級上限就全部被壓住。

- **衝主堡流**：上限高、空間大，但長期沒有軍隊，只能靠聯盟保護
- **衝功能流**：現在就有真實戰力，但天花板早早撞死
- **平衡流**：兩邊都不夠好，但不會死

沒有正確答案，只有**你什麼時候需要什麼**。
而因為所有人同時開賽（見 `13`），你的選擇會立刻被鄰居的選擇檢驗。

> 註：原設計為主堡 Lv10／Lv20 各增加一條建造佇列。
> 那會讓後期玩家「什麼都能蓋」，取捨在最需要取捨的中後期反而消失。
> 改為：主堡提升的是**領土設施佇列**（橫向鋪產出），
> 核心佇列則永遠稀缺。

### 1.2 可選核心建築（B / C / D 三選三）

只有 **3 格**，以下 7 種建築必須捨棄 4 種。這是 v1 最重要的 build 取捨點。

| 建築 | 主要效果 | 適合流派 |
| --- | --- | --- |
| **兵營 Barracks** | 解鎖步／弓兵；招募速度 +5%/等級 | 所有流派幾乎必備 |
| **獸廄 Stable** | 解鎖騎兵；騎兵行軍速度 +2%/等級 | 掠奪流、快攻流 |
| **工坊 Workshop** | 解鎖攻城車與投石機；攻城傷害 +4%/等級 | 攻城流（拔人領土） |
| **倉庫 Depot** | 資源上限 +40%/等級起算；地窖保護量 +80/等級 | 種田流、被打不怕流 |
| **檔案館 Archive** | 解鎖科技樹；研究速度 +6%/等級 | 長線發育流 |
| **城牆 Rampart** | 據點防禦 +8%/等級（乘算，見 `04`） | 龜守流、前線玩家 |
| **醫療帳 Infirmary** | 我方防守陣亡單位 25%+2%/等級 復原為傷兵 | 前線玩家、被集火者 |

**拆除規則**：拆除需 12 小時、退還 30% 累積建材，且 24 小時內不可再拆。
這讓玩家可以轉型，但不能在每次被打之前臨時換 build。

**設計意圖**：
- 沒有兵營就不能練主力步兵 → 純種田流必須靠聯盟保護。
- 沒有工坊就打不掉別人的領土哨塔 → 攻城單位是稀缺的戰略資源，聯盟內部會分工。
- 沒有倉庫就存不住資源 → 被劫掠時損失慘重，逼你要嘛蓋城牆要嘛快花掉。

## 2. 領土系統

### 2.1 基本規則

| 規則 | 說明 |
| --- | --- |
| 領土單位 | 1 格 |
| 容量上限 | `4 × 主堡等級`（Lv1 = 4 格，Lv30 = 120 格） |
| **連通性** | 每一塊領土必須能透過**上下左右四連通**的自有領土路徑回到核心據點 |
| 地形限制 | `MOUNTAIN` 不可佔領；遺跡禁建圈不可佔領 |
| 每格設施 | 每塊領土可蓋 **1 個外部設施** |

### 2.2 佔領流程

```
1. 選擇一格「與自有領土四連通相鄰」的目標格
2. 檢查目標格狀態：
   ├─ 中立空地  → 直接派遣「拓荒隊」，抵達後開始佔領倒數
   └─ 他人領土  → 必須先派兵摧毀該格的守備（哨塔或駐軍），
                   摧毀後該格轉為「動盪中」狀態 30 分鐘，
                   期間任何相鄰玩家皆可派拓荒隊搶佔
3. 拓荒隊抵達後開始「立旗倒數」：
     基礎 30 分鐘 × 地形係數 × (1 + 已擁有領土數 / 20)
   → 領土越多，擴張越慢（自然遞減，抑制單人無限膨脹）
4. 倒數期間若被攻擊且拓荒隊被殲滅 → 佔領失敗
5. 倒數完成 → 該格成為你的領土，塗上聯盟色
```

**拓荒隊成本（隨已有領土遞增）**：

```
糧食 = 200 × (1 + 已有領土數 / 15)
木材 = 150 × (1 + 已有領土數 / 15)
人口 = 0        ← 拓荒完全不消耗人口
```

| 已有領土 | 糧食 | 木材 | 立旗時間（平原） |
| --- | --- | --- | --- |
| 0 | 200 | 150 | 30m |
| 30 | 600 | 450 | 75m |
| 60 | 1,000 | 750 | 120m |
| 120 | 1,800 | 1,350 | 210m |

**同時進行的拓荒上限 = 領土設施佇列數**（`1 + ⌊主堡等級/10⌋`）。

> **設計變更**：原設計要求拓荒隊帶 `5 + ⌊領土/10⌋` 名民兵，
> 且民兵佔人口——擴張因此在跟軍隊搶人口。**已廢除。**
>
> 現在**佔領領土完全不消耗人口**，而且**領土會加速人口成長**
> （見 `03-economy.md` §3.2）。領土不再是軍隊的競爭者，而是軍隊的來源。

### 佔領後，那格是空的

新佔領的領土格**沒有任何駐軍**。想守住它，你得自己派兵或蓋哨塔。

這與遺跡的設計是同一個原則（見 `05` §2.3）：
**難的不是打下來，是守住。**
領土因此變得容易取得、昂貴維持——
而「維持」的成本以三種形式出現：駐軍的人口與糧耗、
哨塔佔掉的設施格、以及區域軍隊容量的分配（見 `16` §2）。

### 2.3 連通性斷裂：孤立狀態

這是領土戰的核心攻防點。

```
若某塊領土失去回到核心的四連通路徑：
  → 立即進入「孤立 ISOLATED」狀態
  → 產出 −50%，且不再受核心據點的防禦科技加成
  → 持續 6 小時後自動放棄，變回中立空地
  → 期間若連通性恢復（重新奪回中間的格子），立刻解除孤立
```

**戰術意義**：你不需要吃掉對手所有 40 塊領土，
只要**切斷那條連接主幹的細頸**，後面 20 塊會自己掉。
玩家因此必須把版圖經營得「厚實」而不是「觸手狀」——這正是我們要的空間決策。

### 2.4 外部設施（每塊領土 1 個）

| 設施 | 產出／效果 | 建造成本（Lv1） | 說明 |
| --- | --- | --- | --- |
| 農田 Farm | 糧食 +30/h | 木 100 | 受 `FOREST` −20% 影響 |
| 伐木場 Sawmill | 木材 +30/h | 木 80 / 石 40 | `FOREST` +25% |
| 採石場 Quarry | 石料 +30/h | 木 120 | `LODE` +40% |
| 鐵礦坑 Mine | 鐵 +20/h | 木 150 / 石 100 | `LODE` +40% |
| 哨塔 Watchtower | 該格 +200 防禦、視野 +4 格；被攻擊時通知 | 木 200 / 石 200 | 守住細頸的關鍵 |
| **前哨營 Outpost** | 可作為行軍**中繼點**重新出發 | 木 500 / 石 500 / 鐵 300 | 見下方 |
| 集市 Market | 開啟與其他玩家的資源交易 | 木 300 / 石 200 | 每據點上限 1 座 |

外部設施等級上限 = 主堡等級 ÷ 2（無條件捨去）。

### 2.5 前哨營 Outpost：地圖尺寸的解方

500×500 的地圖對攻城單位而言太大（見 `04` 行軍時間上限 24h）。
前哨營讓遠征變得可能：

- 部隊可行軍至自己或**同聯盟成員**的前哨營，抵達後停駐（不消耗行軍上限）
- 從前哨營可以發起新的行軍，**距離重新從前哨營起算**
- 前哨營可儲存資源（上限 5,000/種），供駐軍就地補給
- 前哨營每座維護費：糧食 −50/h
- 每位玩家前哨營上限：`主堡等級 ÷ 6`（Lv30 = 5 座）

聯盟因此會共同建設一條「通往遺跡的補給線」，這是賽季中期的主要合作內容。

## 3. 被攻破時會發生什麼

### 3.1 核心據點被攻破

核心據點不會被消滅。攻方成功後可依派遣類型結算：

| 派遣類型 | 結果 |
| --- | --- |
| 突襲 Raid | 掠奪倉庫中未受地窖保護的資源，不破壞建築 |
| 攻擊 Attack | 掠奪資源 + 城牆等級 −1；若攻方帶投石機，可指定 1 座核心建築 −1 級 |
| — | **主堡永遠不會被降到 Lv1 以下**，玩家不會被打退遊 |

### 3.2 領土格被攻破

| 結果 | 說明 |
| --- | --- |
| 該格設施 −1 級（若已 Lv1 則摧毀，格子保留） | |
| 該格進入「動盪中 CONTESTED」30 分鐘 | 期間產出歸零 |
| 動盪結束後若無人搶佔 → 回歸原主 | 所以只是打掉不夠，必須真的派拓荒隊來搶 |

**設計意圖**：搶領土需要兩趟（打 + 佔），成本高於單純劫掠，
所以大多數日常互動是「劫掠」，只有真正的領土戰爭才會發生佔領。
這控制了地圖變動的頻率，讓版圖有穩定感。

## 4. 據點防禦力總覽（供 `04` 引用）

```
守方總防禦 D = Σ(守軍數量 × 該兵種對應攻方類型的防禦值)
             × (1 + 城牆等級 × 0.08)
             × (1 + 地形防禦修正)
             × (1 + 防禦科技加成)
             + 哨塔固定防禦值（僅領土格）
```
