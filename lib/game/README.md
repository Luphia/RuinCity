# /lib/game — 純函式遊戲邏輯

**這個目錄不得有任何 I/O。** 沒有 DB、沒有 fetch、沒有 `Date.now()` 隱式呼叫
（時間一律由呼叫端以參數傳入）。

理由有三個：

1. `scripts/simulate-season.ts` 要能在幾秒內模擬 600 名玩家跑完 12 天賽季，
   用來驗證數值平衡。**數值調整必須先跑模擬再上線。**
2. 事件重放測試要能驗證「同一序列跑兩次結果相同」（冪等）。
3. 戰鬥公式的每一個邊界值都要能單獨測試 ——
   戰報頁面會把計算過程完整展開給玩家看，數字必須經得起手算。

| 檔案 | 內容 | 里程碑 |
| --- | --- | --- |
| `balance/` | 所有數值表（單一真相來源） | M0 ✅ |
| `calendar.ts` | 遊戲曆法與四季係數 | M0 ✅ |
| `economy.ts` | 資源與人口的惰性結算 | M2 |
| `territory.ts` | 連通性檢查、佔領規則 | M2 |
| `steward.ts` | 執政官決策 `decideStewardActions()` | M2b |
| `march.ts` | 行軍時間、預警窗口 | M3 |
| `combat.ts` | 戰鬥公式 | M3 |
| `supply.ts` | 區域軍隊容量與超限損耗 | M3b |
| `ruins.ts` | 遺跡進度與軍團出擊 | M5 / M5d |
